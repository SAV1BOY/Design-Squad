# Opportunity Framing

## Metadata
- **Categoria:** Discovery
- **Complexidade:** Alta
- **Tempo Estimado:** 3-5 dias
- **Squad:** Design
- **Status:** Gold Standard
- **Última Atualização:** 2026-03-06
- **Tags:** discovery, opportunity, strategy, ideation, prioritization

## Objective
Transformar os insights coletados durante discovery em oportunidades de design priorizadas e
acionáveis. Este processo conecta evidências de pesquisa a direções estratégicas, permitindo que
o squad tome decisões informadas sobre onde investir esforço de design.

## Prerequisites
- Problem Definition Document finalizado e aprovado
- Síntese de stakeholder interviews disponível
- Dados de pesquisa com usuários (se disponíveis nesta fase)
- Competitive UI Audit concluído
- Métricas de negócio e product strategy acessíveis
- Sala ou board virtual reservado para workshop colaborativo

## Agents
| Papel | Responsabilidade |
|-------|-----------------|
| Design Lead | Facilitar sessões de framing e consolidar oportunidades |
| Product Manager | Fornecer lente de negócio e viabilidade de mercado |
| UX Researcher | Trazer evidências de pesquisa para embasar oportunidades |
| Tech Lead | Avaliar viabilidade técnica de cada oportunidade |
| Stakeholder | Validar alinhamento estratégico das oportunidades priorizadas |

## Frameworks
- **Opportunity Solution Tree (Teresa Torres)** — para estruturar relação outcome-oportunidade
- **How Might We (HMW)** — para reformular problemas em espaços de oportunidade
- **Impact x Effort Matrix** — para priorizar oportunidades identificadas
- **Value Proposition Canvas** — para validar fit entre oportunidade e necessidade do usuário
- **RICE Scoring** — para quantificar priorização quando necessário

## Checklists
- [ ] Todos os inputs de discovery consolidados e acessíveis
- [ ] Workshop de Opportunity Framing agendado com participantes confirmados
- [ ] Outcome desejado claramente articulado
- [ ] Opportunity Solution Tree construída com pelo menos 3 níveis
- [ ] Mínimo de 10 oportunidades geradas e agrupadas
- [ ] Oportunidades priorizadas via Impact x Effort ou RICE
- [ ] Top 3-5 oportunidades detalhadas com hipóteses e métricas
- [ ] Documento validado por PM e stakeholder
- [ ] Oportunidades priorizadas alimentaram o design backlog

## Steps
1. **Consolidar inputs de discovery** — Reunir todos os artefatos produzidos: problem definition,
   stakeholder insights, competitive audit e dados de analytics. Criar resumo visual.

2. **Definir outcome desejado** — Articular claramente o resultado que o negócio e o usuário
   esperam alcançar. Este outcome será a raiz da Opportunity Solution Tree.

3. **Gerar oportunidades com HMW** — Facilitar sessão de brainstorming onde cada insight é
   transformado em uma pergunta How Might We. Gerar mínimo de 15 HMWs.

4. **Agrupar e categorizar** — Organizar HMWs em clusters temáticos usando Affinity Diagram.
   Nomear cada cluster como uma oportunidade de alto nível.

5. **Construir Opportunity Solution Tree** — Estruturar a árvore com outcome no topo,
   oportunidades no segundo nível e possíveis soluções no terceiro nível.

6. **Avaliar viabilidade técnica** — Para cada oportunidade de alto nível, obter input do Tech
   Lead sobre complexidade, dependências e riscos técnicos.

7. **Priorizar com Impact x Effort** — Posicionar cada oportunidade na matriz considerando
   impacto para o usuário/negócio e esforço estimado de design e engenharia.

8. **Detalhar top oportunidades** — Para as 3-5 oportunidades priorizadas, documentar: hipótese,
   métricas de sucesso, riscos, dependências e próximos passos sugeridos.

9. **Validar e comunicar** — Apresentar oportunidades priorizadas para stakeholders. Obter
   aprovação e integrar ao roadmap de design do squad.

## Output
- **Opportunity Framing Document** — Documento com Opportunity Solution Tree, oportunidades
  priorizadas, hipóteses e próximos passos
- **Opportunity Backlog** — Lista priorizada integrável ao design backlog
- **Formato:** Markdown + Miro/FigJam board para a Opportunity Solution Tree
- **Nomenclatura:** `opportunity-framing-[nome-do-projeto]-[YYYY-MM-DD]`

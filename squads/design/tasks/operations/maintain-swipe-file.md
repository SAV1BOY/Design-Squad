# Maintain Swipe File

## Metadata
- **Categoria:** Operations
- **Complexidade:** Baixa
- **Tempo Estimado:** Contínuo (30 min/semana)
- **Squad:** Design
- **Status:** Gold Standard
- **Última Atualização:** 2026-03-06
- **Tags:** operations, swipe-file, inspiration, references, design-culture

## Objective
Manter uma coleção curada e organizada de referências de design (swipe file) que serve como fonte
de inspiração e benchmark para o squad. O swipe file acelera explorações visuais, informa decisões
de design pattern e promove cultura de aprendizado contínuo.

## Prerequisites
- Ferramenta de coleta configurada (Are.na, Raindrop, Notion, Eagle)
- Taxonomia de categorias definida pelo squad
- Hábito de coleta incentivado entre todos os membros
- Canal de compartilhamento no Slack (ex: #design-inspiration)
- Revisão periódica agendada para curadoria

## Agents
| Papel | Responsabilidade |
|-------|-----------------|
| Todos os designers | Contribuir com referências regularmente |
| Design Ops | Manter organização, curar e moderar qualidade |
| Design Lead | Promover cultura de coleta e compartilhamento |

## Frameworks
- **Swipe File Taxonomy** — categorias: UI patterns, motion, data-viz, typography, illustration
- **Reference Card** — formato: screenshot + URL + contexto + tags
- **Weekly Inspiration Share** — ritual de compartilhamento semanal
- **Seasonal Curation** — revisão e destaque de melhores referências por trimestre
- **Cross-Pollination** — trazer referências de fora do design digital

## Checklists
- [ ] Ferramenta de coleta configurada e acessível a todo o squad
- [ ] Taxonomia de categorias documentada e compartilhada
- [ ] Mínimo de 5 novas referências adicionadas por semana (squad total)
- [ ] Cada referência tem: screenshot, URL, breve contexto e tags
- [ ] Curadoria mensal executada (remover duplicatas, recategorizar)
- [ ] Weekly inspiration share ativo no Slack
- [ ] Referências relevantes linkadas em projetos de design atuais
- [ ] Revisão trimestral de highlights e tendências executada
- [ ] Novas categorias propostas e adicionadas conforme necessidade

## Steps
1. **Configurar ferramenta** — Montar estrutura na ferramenta escolhida com categorias iniciais:
   UI patterns, motion/animation, typography, data visualization, illustration, photography,
   branding, onboarding, empty states, error handling.

2. **Definir formato de contribuição** — Padronizar: screenshot de alta qualidade + URL da fonte
   + 1-2 frases de contexto (por que é interessante) + tags de categoria.

3. **Incentivar coleta contínua** — Promover hábito: extensão de browser para captura rápida,
   lembrete semanal no Slack, reconhecimento de contribuidores frequentes.

4. **Compartilhar semanalmente** — No canal #design-inspiration, postar 2-3 destaques da semana.
   Alternar curador por semana entre membros do squad.

5. **Linkar a projetos** — Ao iniciar exploração visual, buscar referências relevantes no swipe
   file. Criar boards de referência por projeto a partir do acervo.

6. **Curar mensalmente** — Revisar adições do mês: remover duplicatas, recategorizar itens
   mal classificados e destacar referências de alta qualidade.

7. **Expandir horizontes** — Intencionalmente buscar referências fora do design digital:
   arquitetura, editorial, moda, arte, natureza. Cross-pollination inspira soluções originais.

8. **Revisão trimestral** — Compilar highlights do trimestre. Identificar tendências visuais
   recorrentes. Compartilhar compilação em sessão de 20 minutos com o squad.

## Output
- **Curated Swipe File** — Coleção organizada e tagueada de referências
- **Weekly Highlights** — Posts semanais no canal de inspiração
- **Quarterly Trends** — Compilação de tendências observadas
- **Formato:** Ferramenta de coleta + Slack posts
- **Nomenclatura:** Organizado por categorias na ferramenta

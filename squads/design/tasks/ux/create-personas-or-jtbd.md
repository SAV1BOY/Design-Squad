# Create Personas or JTBD

## Metadata
- **Categoria:** UX
- **Complexidade:** Alta
- **Tempo Estimado:** 5-8 dias
- **Squad:** Design
- **Status:** Gold Standard
- **Última Atualização:** 2026-03-06
- **Tags:** ux, personas, jtbd, user-modeling, segmentation

## Objective
Criar representações acionáveis dos usuários do produto utilizando Personas baseadas em dados
e/ou framework de Jobs To Be Done (JTBD). Os artefatos resultantes alinham o squad em torno
de quem são os usuários, o que buscam alcançar e quais são suas motivações fundamentais.

## Prerequisites
- Dados de pesquisa qualitativa (entrevistas, observações) disponíveis
- Dados quantitativos de segmentação (analytics, surveys) disponíveis
- Síntese de insights de pesquisa concluída
- Stakeholder alignment sobre abordagem (Personas, JTBD ou ambos)
- Ferramenta de documentação visual configurada (Figma, Notion)

## Agents
| Papel | Responsabilidade |
|-------|-----------------|
| UX Researcher | Analisar dados, criar artefatos e validar com evidências |
| UX Designer | Colaborar na criação e aplicar personas/JTBD em decisões de design |
| Product Manager | Validar segmentação e alinhar com estratégia de produto |
| Design Lead | Revisar qualidade e garantir adoção pelo squad |
| Content Designer | Ajudar a narrar cenários e contextos dos usuários |

## Frameworks
- **Data-Driven Personas** — personas baseadas em evidências quantitativas e qualitativas
- **Jobs To Be Done (JTBD)** — foco em jobs funcionais, emocionais e sociais
- **Job Stories** — formato: "When [situação], I want to [motivação], so I can [resultado]"
- **Empathy Map** — como complemento visual para cada persona
- **Spectrum of Users** — para evitar personas binárias e contemplar diversidade

## Checklists
- [ ] Dados de pesquisa revisados e patterns de segmentação identificados
- [ ] Abordagem definida: Personas, JTBD ou modelo híbrido
- [ ] 3-5 personas ou 5-8 jobs mapeados a partir dos dados
- [ ] Cada persona contém: contexto, goals, frustrations, behaviors, quotes reais
- [ ] Cada JTBD contém: job statement, situação, motivação, resultado desejado
- [ ] Empathy Maps criados como complemento visual
- [ ] Artefatos revisados pelo squad em sessão colaborativa
- [ ] Personas/JTBD publicados e acessíveis a todo o squad
- [ ] Plano de atualização periódica definido

## Steps
1. **Revisar dados de pesquisa** — Analisar entrevistas, surveys e analytics buscando padrões
   de comportamento, motivação e contexto que diferenciem grupos de usuários.

2. **Identificar clusters** — Agrupar usuários por padrões comportamentais (não demográficos).
   Usar behavioral variables como eixos de diferenciação entre segmentos.

3. **Escolher abordagem** — Decidir com o squad entre Personas (foco em quem), JTBD (foco no
   que) ou modelo híbrido. Justificar escolha com base no tipo de projeto.

4. **Criar draft de Personas** — Para cada segmento, redigir: nome, foto representativa, contexto
   de vida, goals, frustrations, comportamentos-chave, citações reais e cenários de uso.

5. **Mapear JTBD (se aplicável)** — Articular job statements no formato padronizado. Desdobrar
   em jobs funcionais, emocionais e sociais. Mapear hiring e firing criteria.

6. **Criar Empathy Maps** — Para cada persona/JTBD principal, construir Empathy Map visual:
   thinks, feels, says, does. Usar dados reais, evitar suposições.

7. **Validar com squad** — Apresentar artefatos em sessão colaborativa. Coletar feedback sobre
   representatividade, utilidade e lacunas. Ajustar conforme feedback.

8. **Publicar e socializar** — Disponibilizar artefatos finais em local acessível (Figma, Notion).
   Criar versão resumida (poster) para uso rápido no dia a dia.

9. **Definir cadência de atualização** — Estabelecer trigger de revisão: nova rodada de pesquisa,
   mudança significativa no produto ou a cada 6 meses no mínimo.

## Output
- **Persona Cards** — 3-5 personas visuais com dados e narrativa
- **JTBD Map** — 5-8 job statements com desdobramentos
- **Empathy Maps** — Mapa visual por persona principal
- **Formato:** Figma components + Markdown + posters para impressão
- **Nomenclatura:** `personas-jtbd-[nome-do-projeto]-[YYYY-MM-DD]`

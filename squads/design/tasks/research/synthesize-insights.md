# Synthesize Insights

## Metadata
- **Categoria:** Research
- **Complexidade:** Alta
- **Tempo Estimado:** 3-5 dias
- **Squad:** Design
- **Status:** Gold Standard
- **Última Atualização:** 2026-03-06
- **Tags:** research, synthesis, insights, affinity-mapping, atomic-research

## Objective
Consolidar dados e achados de múltiplas fontes de pesquisa em insights acionáveis e priorizados.
A síntese transforma observações fragmentadas em narrativas coerentes que direcionam decisões de
design e alimentam o research repository do squad.

## Prerequisites
- Pelo menos 2 fontes de dados de pesquisa disponíveis (entrevistas, surveys, analytics)
- Notas brutas de pesquisa organizadas e acessíveis
- Ferramenta de síntese configurada (Miro, FigJam, Dovetail ou equivalente)
- Participantes do squad disponíveis para sessão colaborativa de síntese
- Template de Atomic Research Nuggets definido pelo squad

## Agents
| Papel | Responsabilidade |
|-------|-----------------|
| UX Researcher | Liderar síntese, facilitar sessões e redigir documento final |
| Design Lead | Participar da síntese e validar relevância dos insights para design |
| UX Designer | Contribuir com perspectiva de interação e fluxos |
| Product Manager | Contribuir com perspectiva de negócio e priorização |

## Frameworks
- **Affinity Diagram** — agrupamento temático de observações
- **Atomic Research (Nuggets)** — fragmentação em: fact, insight, recommendation
- **Empathy Map** — para consolidar perspectiva do usuário
- **Insight Prioritization Matrix** — impacto do insight x confiança na evidência
- **Thematic Analysis** — codificação sistemática de dados qualitativos

## Checklists
- [ ] Todas as fontes de dados inventariadas e acessíveis
- [ ] Observações extraídas e transferidas para post-its/nuggets
- [ ] Sessão de Affinity Mapping realizada com pelo menos 3 participantes
- [ ] Clusters nomeados e hierarquizados
- [ ] Insights redigidos no formato padrão (observation + so what + now what)
- [ ] Insights priorizados por impacto e confiança
- [ ] Nuggets atômicos registrados no research repository
- [ ] Documento de síntese revisado pelo Design Lead
- [ ] Findings apresentados ao squad

## Steps
1. **Inventariar fontes de dados** — Listar todas as fontes disponíveis: entrevistas, surveys,
   analytics, tickets de suporte, sessões de usabilidade. Verificar completude.

2. **Extrair observações atômicas** — De cada fonte, extrair fatos e observações individuais em
   formato de post-it: uma observação por nota, incluindo fonte e contexto.

3. **Facilitar Affinity Mapping** — Em sessão colaborativa de 90-120 minutos, agrupar observações
   por afinidade temática. Trabalhar bottom-up sem categorias pré-definidas.

4. **Nomear clusters e hierarquizar** — Dar nomes descritivos a cada grupo. Organizar em
   hierarquia de temas e sub-temas quando aplicável.

5. **Redigir insights** — Para cada cluster principal, redigir insight no formato:
   "Observamos [fato]. Isso significa [implicação]. Portanto [recomendação]."

6. **Priorizar insights** — Posicionar cada insight na matriz de impacto x confiança na evidência.
   Insights com alto impacto e alta confiança são prioritários.

7. **Criar nuggets atômicos** — Fragmentar cada insight em unidades reutilizáveis seguindo o
   modelo Atomic Research: Evidence > Fact > Insight > Recommendation.

8. **Registrar no repository** — Catalogar nuggets no research repository com tags, projeto de
   origem, data e link para dados brutos.

9. **Documentar e apresentar** — Redigir documento de síntese executiva e apresentar findings
   para o squad em sessão de 30 minutos com espaço para Q&A.

## Output
- **Insight Synthesis Document** — Documento com insights priorizados e recomendações
- **Atomic Research Nuggets** — Unidades de insight catalogadas no repository
- **Affinity Map** — Board visual com agrupamentos temáticos
- **Formato:** Markdown + Miro/FigJam board + entries no research repository
- **Nomenclatura:** `insight-synthesis-[nome-do-projeto]-[YYYY-MM-DD]`

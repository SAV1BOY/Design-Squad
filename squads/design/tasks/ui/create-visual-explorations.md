# Create Visual Explorations

## Metadata
- **Categoria:** UI
- **Complexidade:** Média
- **Tempo Estimado:** 3-5 dias
- **Squad:** Design
- **Status:** Gold Standard
- **Última Atualização:** 2026-03-06
- **Tags:** ui, visual-exploration, moodboard, style-tiles, art-direction

## Objective
Criar explorações visuais divergentes para definir a direção estética do produto ou feature.
O processo gera múltiplas opções de art direction que são avaliadas e refinadas até convergir
em uma direção visual aprovada, antes de investir em design high-fidelity completo.

## Prerequisites
- Briefing de marca ou diretrizes visuais existentes
- Problem definition e personas disponíveis para contexto
- Competitive UI Audit concluído (referências visuais do mercado)
- Swipe file atualizado com inspirações relevantes
- Ferramenta de design configurada (Figma, Photoshop, Illustrator)

## Agents
| Papel | Responsabilidade |
|-------|-----------------|
| UI Designer | Criar explorações visuais, moodboards e style tiles |
| Design Lead | Direcionar exploração e facilitar decisão sobre direção final |
| Brand Designer | Garantir alinhamento com identidade visual da marca |
| Product Manager | Fornecer contexto de posicionamento e público-alvo |
| Stakeholder | Participar da avaliação e aprovar direção visual |

## Frameworks
- **Moodboard** — colagem de referências visuais que comunicam atmosfera e estilo
- **Style Tiles** — amostra de elementos visuais (cores, tipo, texturas) sem layout
- **Design Concept Testing** — apresentação de 2-3 direções para feedback comparativo
- **Visual Design Principles** — hierarquia, contraste, repetição, alinhamento, proximidade
- **Brand Personality Spectrum** — posicionamento visual entre atributos opostos

## Checklists
- [ ] Briefing criativo documentado (atributos desejados, restrições, público)
- [ ] Pesquisa de referências executada (mínimo 30 referências coletadas)
- [ ] 2-3 moodboards criados com direções visuais distintas
- [ ] Style tiles produzidos para cada direção (cores, tipo, ícones, foto style)
- [ ] 1-2 telas-chave renderizadas em cada direção para comparação
- [ ] Apresentação de conceitos montada com rationale de cada direção
- [ ] Sessão de avaliação com stakeholders realizada
- [ ] Direção final selecionada e documentada com justificativa
- [ ] Refinamentos pós-aprovação incorporados
- [ ] Visual direction guide criado para o projeto

## Steps
1. **Documentar briefing criativo** — Articular com PM e stakeholder: atributos de personalidade
   desejados, público-alvo, restrições de marca e referências apreciadas/evitadas.

2. **Pesquisar referências** — Coletar 30+ referências visuais de diversas fontes: Dribbble,
   Behance, produtos reais, arte, fotografia, arquitetura. Organizar por tema.

3. **Criar moodboards** — Montar 2-3 moodboards com direções visuais distintas. Cada um deve
   comunicar uma atmosfera diferente sem ser literal (não copiar layouts).

4. **Produzir style tiles** — Para cada moodboard, criar style tile com: paleta de cores,
   amostra tipográfica, estilo de iconografia, tratamento de fotos e texturas.

5. **Renderizar telas-chave** — Selecionar 1-2 telas representativas e renderizar em cada
   direção visual. Usar conteúdo real para avaliação contextualizada.

6. **Montar apresentação comparativa** — Criar deck com: briefing, moodboard, style tile e tela
   renderizada lado a lado. Incluir rationale para cada direção.

7. **Facilitar sessão de avaliação** — Apresentar conceitos para stakeholders e squad. Usar
   método de dot voting ou scorecard para estruturar feedback.

8. **Selecionar e documentar direção** — Com base no feedback, selecionar a direção final.
   Documentar justificativa, feedback incorporado e refinamentos necessários.

9. **Criar visual direction guide** — Consolidar a direção aprovada em um guia de referência
   com: paleta, tipografia, estilo de imagem, tom visual e do's/don'ts.

## Output
- **Moodboards** — 2-3 colagens de referências visuais
- **Style Tiles** — Amostras de elementos visuais por direção
- **Visual Direction Guide** — Guia consolidado da direção aprovada
- **Formato:** Figma file + PDF para apresentação
- **Nomenclatura:** `visual-exploration-[nome-do-projeto]-[YYYY-MM-DD]`

# Phase: Release Notes

## Objective

Documentar e comunicar mudancas do upgrade para todos os consumidores do DS.

## Inputs

- Changelog tecnico
- Migration guides
- Metricas de adocao

## Activities

1.

Changelog: documentar todas as mudancas (new, changed, deprecated, removed).

2.

Migration Guide: passo-a-passo para cada breaking change.

3.

Visual Diff: before/after de componentes alterados.

4.

Communication: enviar release notes por email/Slack.

5.

Office Hours: sessao de Q&A pos-release.

6.

Retrospective: review do processo de upgrade com o time.

## Output

- Release notes publicadas
- Migration guides por componente
- Communication enviada
- Retrospective documentada

# Phase: Token Architecture Plan

## Objective

Definir a arquitetura de tokens para o upgrade — nomenclatura, camadas, formatos e tooling.

## Inputs

- Inventario de tokens atuais (00-inventory.md)
- Benchmarks de DS publicos
- Requirements de theming (light
- dark
- brand)

## Activities

1.

Token Taxonomy: definir 3 camadas (global, alias, component).

2.

Naming Convention: definir padrao de nomenclatura com exemplos.

3.

Theme Support: mapear valores por tema (light, dark).

4.

Tooling Selection: avaliar Style Dictionary, Token Studio, Figma Variables.

5.

Migration Path: planejar como migrar de valores hard-coded para tokens.

6.

Validation: testar com 2-3 componentes piloto.

## Output

- Documento de arquitetura de tokens
- Naming convention definida
- Token files piloto (JSON)
- Tooling configurado
- Migration plan

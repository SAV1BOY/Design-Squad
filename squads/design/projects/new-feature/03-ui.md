# Phase: UI Design

## Objective

Aplicar design visual sobre os wireframes aprovados — tokens, componentes, tipografia, cores e micro-interacoes para criar a interface final de alta fidelidade.

## Inputs

- Wireframes aprovados (02-ux.md)
- Design system (lib/ — components, tokens, patterns)
- Brand guidelines (se aplicavel)
- Accessibility requirements (WCAG AA)

## Activities

### 1. Visual Design
```
- Aplicar tokens do design system (cores, tipografia, spacing)
- Usar componentes existentes do DS quando possivel
- Projetar componentes novos seguindo padroes do DS
- Definir iconografia e ilustracoes necessarias
```

### 2. States & Interactions
```
- Todos os estados interativos (hover, focus, active, disabled)
- Micro-interacoes e transicoes
- Loading states (skeleton, spinner)
- Error states com mensagens especificas
- Empty states com CTA
- Success states com feedback
```

### 3. Responsive Design
```
- Desktop (1240px+)
- Tablet (768-1239px)
- Mobile (< 768px)
- Adaptacoes de layout por breakpoint
- Touch targets validados (min 44px)
```

### 4. Accessibility Review
```
- Contraste de cor validado (AA: 4.5:1 texto, 3:1 UI)
- Focus order logico
- ARIA labels definidos para elementos interativos
- Reduced motion alternatives
- Screen reader flow documentado
```

### 5. Quality Check
```
- Design quality rubric aplicada (target: 4.0+)
- Pixel perfection check
- Consistencia com outras areas do produto
- Review com Engineering para viabilidade
```

## Output

- Telas finais em alta fidelidade (Figma)
- Todos os estados documentados
- Responsive variants
- Redlines / specs para desenvolvimento
- Componentes novos propostos para o DS

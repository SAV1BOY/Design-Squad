# Phase: Prototype & Validation

## Objective

Criar prototipo interativo e validar a solucao com usuarios reais antes do desenvolvimento. Reduz risco de construir algo que nao funciona.

## Inputs

- UI designs finais (03-ui.md)
- Cenarios de teste da research (01-research.md)
- Metricas de sucesso do brief (00-brief.md)
- Perfil de usuarios para recrutamento

## Activities

### 1. Prototype Creation
```
Fidelidade: alta (visual final com interacoes)
Ferramenta: Figma prototyping ou Framer
Escopo: fluxos principais + 1-2 edge cases

Checklist:
- [ ] Fluxo principal completo e clicavel
- [ ] Transicoes entre telas definidas
- [ ] Estados de erro simulados
- [ ] Dados realistas (nao lorem ipsum)
- [ ] Responsivo (se teste inclui mobile)
```

### 2. Test Planning
```
Metodo: usability test moderado (remoto ou presencial)
Participantes: 5-8 usuarios do perfil target
Duracao: 30-45 min por sessao
Tasks: 3-5 tarefas baseadas nos fluxos principais

Script:
- Intro e consentimento (5 min)
- Contextualizacao sem influenciar (3 min)
- Tarefas com think-aloud (20-30 min)
- Perguntas de follow-up (5-10 min)
```

### 3. Usability Testing
```
Metricas coletadas:
- Task completion rate (% que completou cada tarefa)
- Time on task (tempo medio por tarefa)
- Error rate (% que cometeu erro por tarefa)
- Satisfaction (escala 1-5 por tarefa)
- Qualitative feedback (observacoes e citacoes)
```

### 4. Analysis & Iteration
```
- Affinity mapping de observacoes
- Severity rating de problemas encontrados
- Iteracao rapida no prototipo
- Re-teste de problemas criticos (se necessario)
- Decisao: ship, iterate, or pivot
```

## Output

- Prototipo interativo testado
- Usability test report com findings e recomendacoes
- Iteracoes pos-teste documentadas
- Go/no-go decision para desenvolvimento
- Updated designs com correcoes de usabilidade

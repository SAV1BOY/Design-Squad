# Phase: UX Design

## Objective

Definir a experiencia do usuario — fluxos, arquitetura de informacao, wireframes e logica de interacao antes do design visual.

## Inputs

- Research report (01-research.md)
- HMW statements e oportunidades priorizadas
- Constraints tecnicas do Engineering
- Design system components disponiveis

## Activities

### 1. Ideation
```
- Sketching session (30 min, 3+ alternativas)
- Crazy 8s para explorar rapidamente
- Review de swipe file para patterns relevantes
- Discussao com Engineering sobre viabilidade
```

### 2. Information Architecture
```
- User flows para cenarios principais
- Sitemap ou tree (se navegacao envolvida)
- Content hierarchy por tela
- Edge cases mapeados (error, empty, loading)
```

### 3. Wireframes
```
- Low-fidelity wireframes (grayscale, sem tokens)
- Todas as telas do fluxo principal
- Estados: default, loading, empty, error, success
- Responsive considerations (mobile e desktop)
- Anotacoes de comportamento e logica
```

### 4. Review & Iteration
```
- Design critique com time (usando framework I Like/I Wish/What If)
- Feedback de Engineering sobre viabilidade
- Feedback de PM sobre scope alignment
- 2-3 iteracoes baseadas em feedback
```

## Output

- User flows documentados
- Wireframes de todas as telas e estados
- Anotacoes de comportamento
- Edge cases documentados
- UX aprovada para fase de UI

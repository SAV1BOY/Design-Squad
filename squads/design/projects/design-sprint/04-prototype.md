# Phase: Day 4 — Prototype

## Objective

Construir prototipo realista em um unico dia. O prototipo deve ser convincente o suficiente para obter reacoes reais de usuarios.

## Inputs

- Storyboard aprovado (03-decide.md)
- Assets do design system (tokens, componentes)
- Conteudo real (copy, dados, imagens)
- Ferramenta de prototipo (Figma, Keynote)

## Activities

### 1. Divide & Conquer (Morning, 30 min)
Dividir tarefas entre o time: Makers (2-3 pessoas): constroem o prototipo no Figma. Writer (1 pessoa): cria todo o copy real. Collector (1 pessoa): busca assets (imagens, icones, dados). Interviewer (1 pessoa): prepara script e logistica de teste.

### 2. Build (Full Day)
Makers constroem telas seguindo o storyboard. Usar componentes do DS quando possivel, criar mockups quando nao. Fidelidade: Goldilocks — convincente mas nao perfeito. Cada tela deve ter dados realistas.

### 3. Stitch Together (Late Afternoon)
Conectar telas com transicoes clicaveis. Testar fluxo completo internamente. Corrigir gaps e inconsistencias. Trial run: 1 pessoa do time faz o teste como usuario.

### 4. Test Prep
Confirmar 5 usuarios para amanha. Preparar ambiente de teste (sala, Zoom, recording). Revisar script de teste. Preparar grid de notas para observadores.

## Output

- Prototipo interativo completo
- Script de teste finalizado
- 5 usuarios confirmados para Day 5
- Ambiente de teste preparado
- Grid de notas para o time

# Day 4: Prototype

## Objetivo do Dia

Construir um prototipo realista o suficiente para testar com
usuarios reais no dia 5. O prototipo deve cobrir o fluxo
definido no storyboard do dia 3.

## Principio do Prototipo

O prototipo deve ser uma **fachada** — parecer real o suficiente
para o usuario interagir naturalmente, mas sem funcionalidade
real por tras.

### Nivel de Fidelidade Alvo

| Aspecto | Nivel | Justificativa |
|---------|-------|---------------|
| Visual | Mid-High | Parecer produto real |
| Conteudo | High | Textos reais, dados realisticos |
| Interacao | Mid | Fluxo principal navegavel |
| Animacoes | Low | Apenas transicoes basicas |
| Dados | Low | Dados estaticos/mockados |

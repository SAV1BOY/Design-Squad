# Phase: Synthesis & Analysis

## Objective

Transformar dados brutos de pesquisa em insights acionaveis atraves de analise sistematica e colaborativa.

## Inputs

- Notas e gravacoes das sessoes (02-execute.md)
- Hipoteses originais (00-objectives.md)
- Daily synthesis notes
- Dados quantitativos complementares (se disponível)

## Activities

### 1. Data Download
Cada membro do time revisa suas notas e as organiza em atomic insights (1 observacao por post-it/card). Formato: "[Participante] [fez/disse/sentiu] [observacao]." Usar codificacao de cor por participante.

### 2. Affinity Mapping
Agrupar insights em clusters tematicos (silenciosamente). Rotular cada cluster com um tema descritivo. Identificar temas majoritarios (aparecem em 3+ participantes). Separar outliers (insights unicos mas potencialmente importantes).

### 3. Pattern Identification
Para cada tema: quantos participantes? Quais segmentos? Qual a intensidade (mencionou vs reclamou vs bloqueou)? Correlacionar com dados quantitativos quando possivel. Validar ou invalidar hipoteses originais.

### 4. Insight Generation
Transformar padroes em insights acionaveis. Formato: "Porque [evidencia], sabemos que [insight], portanto deveríamos [implicacao]." Priorizar insights por impacto e confianca. Gerar HMW (How Might We) para cada insight.

### 5. Persona/Journey Update
Atualizar personas e journey maps com novos dados. Adicionar citacoes reais. Destacar novos pain points e oportunidades descobertos.

## Output

- Affinity map documentado
- Lista priorizada de insights com evidencia
- Hipoteses validadas/invalidadas
- HMW statements para ideacao
- Personas e journey maps atualizados
- Highlights reel (video clips, 5-10 min)

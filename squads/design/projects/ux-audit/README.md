# UX Audit Project Template

## Overview

Template para projetos de auditoria de UX. Este conjunto de documentos
guia o time atraves de uma avaliacao sistematica da experiencia do
usuario, desde a avaliacao heuristica ate o plano de acao.

## Estrutura do Template

| Arquivo | Descricao | Fase |
|---------|-----------|------|
| `heuristic-evaluation.md` | Avaliacao heuristica | Analise |
| `findings-report.md` | Relatorio de findings | Sintese |
| `recommendations.md` | Recomendacoes | Proposta |
| `action-plan.md` | Plano de acao | Execucao |

## Como Usar

1. Defina o escopo da auditoria (produto, fluxo, ou feature)
2. Conduza a avaliacao heuristica usando o template
3. Consolide os findings no relatorio
4. Elabore recomendacoes priorizadas
5. Crie o plano de acao com timeline e responsaveis

## Fluxo do Projeto

```
Definicao de Escopo → Avaliacao Heuristica → Findings → Recomendacoes → Plano de Acao
```

## Tipos de Auditoria

### Auditoria Completa

Avaliacao abrangente de todo o produto ou plataforma.
- **Duracao estimada**: 3-4 semanas
- **Time necessario**: 2-3 designers + 1 researcher
- **Entregavel principal**: Relatorio completo + roadmap

### Auditoria Focada

Avaliacao de um fluxo ou feature especifica.
- **Duracao estimada**: 1-2 semanas
- **Time necessario**: 1-2 designers
- **Entregavel principal**: Relatorio focado + quick wins

### Auditoria Competitiva

Avaliacao comparativa com produtos concorrentes.
- **Duracao estimada**: 2-3 semanas
- **Time necessario**: 1-2 designers + 1 researcher
- **Entregavel principal**: Analise comparativa + oportunidades

## Heuristicas de Referencia

Este template utiliza as 10 heuristicas de Nielsen como framework
principal, complementadas por heuristicas de acessibilidade.

1. Visibilidade do status do sistema
2. Correspondencia entre sistema e mundo real
3. Controle e liberdade do usuario
4. Consistencia e padroes
5. Prevencao de erros
6. Reconhecimento ao inves de recordacao
7. Flexibilidade e eficiencia de uso
8. Estetica e design minimalista
9. Ajuda para reconhecer, diagnosticar e recuperar erros
10. Ajuda e documentacao

## Ferramentas Recomendadas

| Ferramenta | Uso |
|-----------|-----|
| Figma | Anotacoes e screenshots |
| Miro / FigJam | Mapeamento de findings |
| Spreadsheet | Matriz de severidade |
| Loom | Gravacao de walkthroughs |
| axe DevTools | Auditoria de acessibilidade |

## Metricas de Sucesso

- **Coverage**: percentual do produto auditado
- **Findings**: numero total de issues identificados
- **Quick wins**: issues resolviveis em menos de 1 sprint
- **Adoption**: percentual de recomendacoes implementadas

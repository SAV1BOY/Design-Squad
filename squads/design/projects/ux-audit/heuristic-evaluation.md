## Metodologia

Avaliacao baseada nas 10 heuristicas de usabilidade de Jakob Nielsen,
com escala de severidade de 0 a 4.

### Escala de Severidade

| Nivel | Descricao | Acao |
|-------|-----------|------|
| 0 | Nao e um problema de usabilidade | Nenhuma |
| 1 | Problema cosmetico — corrigir apenas se sobrar tempo | Baixa prioridade |
| 2 | Problema menor — baixa prioridade para correcao | Media prioridade |
| 3 | Problema maior — alta prioridade para correcao | Alta prioridade |
| 4 | Catastrofe de usabilidade — imperativo corrigir | Urgente |

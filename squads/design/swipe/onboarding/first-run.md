# First Run Experience Patterns

## Pattern Description

Padroes de primeira execucao (first-run experience) que guiam novos usuarios do registro ate o primeiro momento de valor. O objetivo e reduzir time-to-value e aumentar activation rate.

## Examples

### Example 1: Notion — Progressive Setup

Notion apresenta um onboarding minimalista:
- Tela de boas-vindas com pergunta sobre uso (pessoal, equipe, escola)
- Templates sugeridos com base na resposta
- Workspace pre-populado com conteudo de exemplo editavel
- Tooltips contextuais no primeiro uso de cada feature

Destaque: o conteudo de exemplo funciona como tutorial interativo — o usuario aprende fazendo, nao lendo.

### Example 2: Linear — Guided Import

Linear foca em migracao de dados como first-run:
- Wizard de importacao (Jira, Asana, GitHub Issues)
- Preview dos dados antes de confirmar importacao
- Configuracao de workflows durante o processo
- Dashboard funcional imediatamente apos importacao

Destaque: reconhece que usuarios vem de outro produto e remove a barreira de migracao.

### Example 3: Figma — Playground Canvas

Figma oferece um canvas interativo no primeiro acesso:
- Arquivo de tutorial com instrucoes visuais
- Areas interativas para praticar ferramentas
- Progresso salvo automaticamente
- CTA para criar primeiro arquivo real apos completar

Destaque: ensina a ferramenta dentro da propria ferramenta, sem sair do contexto.

## Analysis

First-run experiences eficazes compartilham:
- **Valor rapido**: usuario alcanca resultado tangivel em < 5 minutos
- **Personalizacao**: adapta o caminho com base no perfil/objetivo
- **Conteudo real**: usa dados do usuario ou exemplos realistas, nao lorem ipsum
- **Escape hatch**: sempre permite pular e explorar livremente
- **Progresso visivel**: mostra quanto falta para completar setup

Metricas-chave: activation rate, time-to-value, setup completion rate, D1/D7 retention.

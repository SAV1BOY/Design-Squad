# Activation Patterns

## Pattern Description

Padroes de ativacao que levam usuarios do registro ao "aha moment" — o ponto em que percebem o valor do produto. Ativacao e o passo mais critico do funil de adocao.

## Examples

### Example 1: Slack — Send First Message

Slack define ativacao como "enviar primeira mensagem em um canal":
- Onboarding cria canal #geral automaticamente
- Slackbot envia mensagem de boas-vindas interativa
- Prompt contextual para enviar primeira mensagem
- Resposta imediata do Slackbot simulando conversa

Destaque: a ativacao e uma acao social simples que demonstra o valor core do produto.

### Example 2: Dropbox — Upload First File

Dropbox usa um checklist de ativacao progressiva:
- Upload primeiro arquivo (acao unica mais importante)
- Instalar app desktop
- Compartilhar uma pasta
- Cada passo desbloqueado com bonus de espaco

Destaque: gamificacao sutil com recompensas tangíveis (mais espaco) por cada acao de ativacao.

### Example 3: Canva — Create First Design

Canva guia ate a criacao do primeiro design:
- Pergunta "o que voce quer criar?" no primeiro acesso
- Sugere template baseado na resposta
- Editor aberto com template pre-selecionado
- Publicacao/download como conclusao da ativacao

Destaque: reduz a barreira criativa oferecendo ponto de partida visual.

## Analysis

Padroes de ativacao eficazes:
- **Aha moment definido**: a equipe sabe exatamente qual acao = ativacao
- **Caminho curto**: minimo de passos entre registro e ativacao
- **Valor demonstrado**: a acao de ativacao mostra (nao conta) o valor
- **Dados informam**: metricas de ativacao guiam otimizacao continua
- **Sem bloqueios**: nenhuma feature gate antes da ativacao

Correlacao: usuarios que ativam em D0 tem 3-5x mais retencao em D30.

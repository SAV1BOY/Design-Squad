# Zero Data Patterns

## Pattern Description

Padroes para estados de zero dados — quando o usuario ainda nao criou conteudo. Zero data e uma oportunidade de onboarding, nao um beco sem saida.

## Examples

### Example 1: Trello — Board Template Suggestion
Trello transforma zero data em convite:
- Ilustracao colorida e amigavel
- "Crie seu primeiro board" como titulo encorajador
- Sugestoes de templates populares como atalho
- CTA primario para criar board em branco
- Link para tutorial/documentacao como alternativa

### Example 2: GitHub — Repository Empty State
GitHub guia setup no repositorio vazio:
- Instrucoes de comando git para primeiro push
- Quick setup via HTTPS ou SSH
- Opcao de importar repositorio existente
- README template auto-geravel
- Tabs de repositorio desabilitadas ate primeiro commit

### Example 3: Notion — Inspiring Empty Page
Notion transforma pagina vazia em canvas inspirador:
- Cursor piscando com placeholder "Type / for commands"
- Sugestoes contextuais baseadas no tipo de pagina
- Templates acessiveis via /template
- AI assistant como opcao de preenchimento

## Analysis

Zero data eficaz:
- **Educacional**: explique o que aparecera aqui quando houver dados
- **Acionavel**: CTA claro para criar primeiro item
- **Templates**: ofereça ponto de partida para reduzir blank-page anxiety
- **Tom amigavel**: "Ainda nao ha projetos" em vez de "Nenhum projeto encontrado"
- **Contextual**: mensagem e CTA devem ser relevantes para a secao

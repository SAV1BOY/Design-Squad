# Notification Inbox Patterns

## Pattern Description

Padroes para centros de notificacao (inbox) que agregam alertas, atualizacoes e mensagens em um unico local acessivel.

## Examples

### Example 1: GitHub — Notification Center
GitHub organiza notificacoes por repositorio:
- Icone de sino no header com badge de contagem
- Lista agrupada por repositorio
- Filtros: Unread, Participating, Mentioned
- Acoes em batch: Mark as read, Done, Save
- Keyboard shortcuts (e, s, y)

### Example 2: Linear — Activity Inbox
Linear combina notificacoes com atividade:
- Inbox com notificacoes actionaveis
- Separacao: Unread | Archive
- Cada item com contexto (issue, comment, mention)
- Click navega para o item original
- Mark all as read como acao rapida

### Example 3: Figma — Comment Notifications
Figma centraliza comentarios como notificacoes:
- Panel lateral com lista de comentarios
- Filtro: All, Mentions, Resolved
- Preview do comentario com link para posicao no canvas
- Badge no icone de sino com contagem de nao lidos
- Notificacoes agrupadas por arquivo

## Analysis

Notification inbox eficaz:
- **Agrupamento**: agrupe por fonte, tipo ou tempo
- **Filtros**: unread, mentions, by type
- **Bulk actions**: mark all read, dismiss all
- **Contexto**: mostre informacao suficiente sem precisar navegar
- **Deep link**: click leva diretamente ao contexto relevante
- **Controle**: configuracoes de quais notificacoes receber

# Public Design System Showcase

## Pattern Description

Analise comparativa de design systems publicos como referencia para decisoes de arquitetura, documentacao e apresentacao.

## Examples

### Example 1: Vercel Geist — Minimal and Functional
Geist Design System da Vercel:
- Documentacao minimalista focada em codigo
- Live preview de cada componente
- Dark mode first approach
- Tokens em CSS variables nativas
- Fonte proprietaria (Geist Sans/Mono) integrada
- Open source com repositorio ativo

### Example 2: Radix UI — Headless Components
Radix oferece abordagem headless:
- Componentes sem estilo visual (unstyled)
- Foco total em acessibilidade e comportamento
- Composicao via primitives (Slot, Compose)
- Documentacao exemplar de a11y por componente
- Temas via Radix Themes como camada visual opcional

### Example 3: Ant Design — Enterprise Scale
Ant Design para aplicacoes enterprise:
- 60+ componentes documentados em chines e ingles
- Design values explicitamente documentados
- Theme customization via config provider
- Pro components para cenarios complexos (ProTable, ProForm)
- Community com 90K+ stars no GitHub

## Analysis

Design systems publicos de referencia:
- **Documentacao**: Carbon e Polaris sao benchmark de docs
- **Acessibilidade**: Radix e referencia de a11y-first
- **Tokens**: Style Dictionary (Amazon) e padrao de tooling
- **Governanca**: Atlassian documenta processo exemplarmente
- **Performance**: Geist e exemplar em bundle size minimo
- **Adocao**: Ant Design demonstra escala global de adocao

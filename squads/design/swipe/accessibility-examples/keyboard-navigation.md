# Keyboard Navigation Examples

## Pattern Description

Exemplos de implementacao excelente de navegacao por teclado em produtos reais. Keyboard navigation e essencial para usuarios de screen readers, usuarios motores e power users.

## Examples

### Example 1: GitHub — Comprehensive Keyboard Support
GitHub oferece suporte extensivo a teclado:
- `?` abre modal de keyboard shortcuts
- `g` + `n` navega para Notifications
- `g` + `c` navega para Code
- `/` foca na barra de busca
- `j`/`k` navega entre items em listas (Vim-style)
- Tab order logico em todas as paginas

### Example 2: Gmail — Keyboard Power Users
Gmail e completamente operavel por teclado:
- `c` compose novo email
- `e` archive
- `#` delete
- `?` abre help de shortcuts
- Arrow keys navegam entre emails
- Custom shortcuts configuráveis

### Example 3: Figma — Canvas Keyboard Control
Figma permite operacao do canvas por teclado:
- Arrow keys movem objetos selecionados
- Tab seleciona proximo objeto
- Enter entra em grupo/frame
- Escape sai do contexto atual
- Shortcuts customizáveis para plugins

## Analysis

Keyboard navigation eficaz:
- **Discoverable**: lista de shortcuts acessivel (`?` key)
- **Consistente**: patterns comuns (Tab, Enter, Escape, Arrows)
- **Skip links**: pular para conteudo principal
- **Focus visible**: ring claro em todos os elementos focaveis
- **Logical order**: tab order segue fluxo visual da pagina
- **No traps**: nenhum componente "prende" o foco sem saida

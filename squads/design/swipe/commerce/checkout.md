# Checkout Patterns

## Pattern Description

Padroes para fluxos de checkout que maximizam conversao atraves de simplicidade, confianca e transparencia. Cada passo removido do checkout pode aumentar conversao em 10-35%.

## Examples

### Example 1: Shopify — One-Page Checkout
Shopify condensou checkout em uma pagina:
- Informacoes, frete e pagamento em secoes expansiveis
- Order summary sempre visivel na lateral
- Express checkout (Apple Pay, Google Pay) no topo
- Guest checkout sem obrigar cadastro
- Preco total atualizado em tempo real

### Example 2: Amazon — One-Click Purchase
Amazon minimizou checkout ao extremo:
- "Buy Now with 1-Click" para compra instantanea
- Endereco e pagamento padrao pre-selecionados
- Confirmacao com undo (janela de 30 min para cancelar)
- Review order page para compras maiores

### Example 3: Stripe Checkout — Hosted Solution
Stripe oferece checkout pre-construido:
- Pagina otimizada para conversao mobile
- Deteccao automatica de bandeira do cartao
- Saved payment methods para clientes recorrentes
- Localizacao automatica (idioma, moeda, metodos de pagamento)
- A/B tested por milhoes de transacoes

## Analysis

Checkout eficaz:
- **Menos passos**: consolide informacoes em 1-3 etapas
- **Guest checkout**: nunca obrigue cadastro para comprar
- **Trust signals**: selos de seguranca, logos de pagamento
- **Transparencia**: total final visivel sem surpresas
- **Error recovery**: preserve dados em caso de erro
- **Mobile optimized**: botoes grandes, teclado numerico para cartao

## Objective

Avaliar o modelo organizacional do time responsavel pelo design system, verificando
se a estrutura, papeis e processos sao adequados para sustentar, evoluir e escalar
o sistema. O modelo de time impacta diretamente a velocidade de evolucao e a
qualidade das entregas do design system.

## When to Apply

- Em reestruturacoes organizacionais que afetam o time de design system.
- Ao planejar contratacoes ou realocacoes para o time.
- Em avaliacoes anuais de eficacia do modelo operacional.
- Quando o design system apresenta sinais de estagnacao ou baixa adocao.

## Criteria

- [ ] O modelo de time esta definido (centralizado, federado, hibrido) e documentado.
- [ ] Papeis dentro do time sao claros: designer, desenvolvedor, PM, QA, tech writer.
- [ ] Existe lideranca dedicada ao design system com autoridade e autonomia.
- [ ] O time possui capacidade alocada para trabalho proativo (nao apenas reativo).
- [ ] Existe modelo de contribuicao claro para squads externos ao time core.
- [ ] O time possui metricas proprias de performance e impacto.
- [ ] Existe interacao regular entre o time do design system e squads consumidores.
- [ ] O time participa de decisoes de produto que impactam o ecossistema visual.
- [ ] Existe plano de sucessao para papeis criticos dentro do time.
- [ ] Budget e headcount sao revisados periodicamente com base na demanda.
- [ ] O time realiza demos regulares de novas funcionalidades e melhorias.
- [ ] Existe programa de rotacao para designers de outros squads contribuirem.
- [ ] O modelo e revisado periodicamente para adaptar-se ao crescimento da organizacao.

## Severity Guide

| Nivel    | Descricao                                                                 |
|----------|---------------------------------------------------------------------------|
| Critical | Nenhum time dedicado ao design system ou lideranca ausente.               |
| Major    | Time apenas reativo sem capacidade para trabalho proativo.                |
| Minor    | Papeis imprecisos ou modelo de contribuicao externa nao definido.         |
| Info     | Oportunidade de implementar programa de rotacao ou melhorar demos.        |

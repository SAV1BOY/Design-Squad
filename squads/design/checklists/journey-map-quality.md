# Journey Map Quality Checklist

## Metadata
- **Squad:** Design
- **Domain:** UX Strategy
- **Version:** 1.0.0
- **Owner Agent:** Experience Mapping Agent

## Objective
Assegurar que journey maps representem com precisao a experiencia real do usuario, identificando oportunidades claras de melhoria.
Um journey map de qualidade e uma ferramenta de alinhamento estrategico, nao apenas um diagrama decorativo.

## When to Apply
- Ao mapear a experiencia atual (as-is) ou futura (to-be) do usuario.
- Ao apresentar a jornada para stakeholders de diferentes areas.
- Quando se precisa identificar gaps entre expectativa e experiencia real.

## Criteria
- [ ] O journey map esta baseado em dados de pesquisa, nao em suposicoes do time
- [ ] A persona associada ao journey map esta identificada e documentada
- [ ] As fases (phases) da jornada estao claramente definidas e nomeadas
- [ ] Cada phase inclui as acoes concretas realizadas pelo usuario
- [ ] Os touchpoints com o produto ou servico estao mapeados em cada fase
- [ ] Os pensamentos e emocoes do usuario estao representados com evidencias
- [ ] Os pain points estao identificados e priorizados por impacto
- [ ] Os moments of delight estao identificados para serem preservados ou amplificados
- [ ] Os canais (channels) utilizados em cada touchpoint estao indicados
- [ ] As oportunidades de melhoria estao conectadas aos pain points identificados
- [ ] O emotional curve esta representado visualmente ao longo da jornada
- [ ] Os backstage processes relevantes estao mapeados quando aplicavel
- [ ] O scope do journey map (inicio e fim) esta claramente delimitado
- [ ] As metricas associadas a cada fase estao indicadas quando disponiveis
- [ ] O formato e de facil leitura e compartilhamento entre times

## Severity Guide

### Critico
- Journey map baseado inteiramente em suposicoes sem dados de pesquisa.
- Fases da jornada nao representam a experiencia real do usuario.
- Ausencia de pain points ou oportunidades de melhoria.

### Major
- Emocoes e pensamentos do usuario nao estao representados.
- Touchpoints importantes estao ausentes do mapeamento.
- Falta de conexao entre pain points e oportunidades.

### Minor
- Emotional curve ausente mas pain points estao documentados.
- Backstage processes nao mapeados em jornada complexa.
- Formatacao visual poderia facilitar mais a leitura.

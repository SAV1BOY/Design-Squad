# User Feedback Reporting

## Context

Frases prontas para reportar e sintetizar feedback de usuários — seja de pesquisa
formal, tickets de suporte, reviews em app stores, ou canais de feedback direto.
O objetivo é transformar feedback bruto em informação acionável para o time de
produto e design.

**Aplicação:** Reports de feedback, sprint planning, apresentações de insights
**Tom:** User Advocate + Evidence-Driven

## Phrases

### Sintetizando feedback quantitativo
- "No último [período], recebemos [N] feedbacks sobre [tema]. [X]% negativos, [Y]% neutros, [Z]% positivos."
- "O tema mais recorrente em tickets de suporte é [tema] — [N] ocorrências em [período]."
- "A nota média no app store para [feature] é [valor]/5, com [N] menções específicas a [problema]."
- "O NPS do [fluxo/feature] é [valor]. Os detratores citam principalmente: (1) [tema], (2) [tema], (3) [tema]."
- "O CSAT do último release caiu [N] pontos. Os verbatims indicam [causa principal]."

### Compartilhando verbatims impactantes
- "Um usuário escreveu: '[verbatim]'. Esse sentimento foi ecoado por mais [N] feedbacks similares."
- "A frase que melhor resume o feedback recebido é: '[verbatim]'."
- "Citação literal de ticket de suporte: '[verbatim]'. O agente de suporte gastou [N] minutos para resolver."
- "Review no app store (3 dias atrás, [N] likes): '[verbatim]'. Esse review representa um padrão."

### Categorizando feedback
- "Agrupamos o feedback em [N] categorias: [lista com percentual de cada]."
- "Os temas emergentes deste mês são: [lista]. Novidade em relação ao mês anterior: [tema novo]."
- "Feedback funcional (bugs): [N]%. Feedback de usabilidade: [N]%. Feedback de feature request: [N]%."
- "Segmentando por perfil: novos usuários reclamam de [A], veteranos reclamam de [B]."

### Conectando feedback a ações
- "Este feedback suporta a priorização de [feature/fix] no backlog."
- "Se endereçarmos os top 3 temas de feedback, cobrimos [X]% das reclamações recebidas."
- "Proponho converter este feedback em [N] tickets de design: [lista com prioridade]."
- "O padrão de feedback confirma o insight de pesquisa sobre [tema]. Hora de agir."

### Acompanhando impacto de mudanças
- "Após o lançamento de [mudança], o feedback sobre [tema] caiu [X]% em [período]."
- "A mudança em [feature] gerou [N] feedbacks positivos espontâneos — antes havia zero."
- "O fix de [problema] reduziu tickets de suporte sobre o tema de [N] para [M] por semana."
- "A percepção do usuário melhorou: NPS da feature subiu de [X] para [Y] pós-mudança."

### Escalando feedback crítico
- "URGENTE: [N] usuários reportaram [problema] nas últimas [N] horas. Impacto: [descrição]."
- "Feedback indica possível regressão em [feature] após deploy de [data]. Verificar [métrica]."
- "Padrão incomum: [N] reclamações sobre [problema] que não existia antes. Possível bug."

## Variations

- Para report semanal: top 5 temas + tendência + action items
- Para sprint planning: feedback traduzido em user stories priorizadas
- Para C-level: 3 métricas + 1 verbatim impactante + 1 recomendação
- Para retrospectiva: feedback como input para melhoria de processo

## When to Use

- Reports periódicos de voz do cliente (semanal, mensal)
- Sprint planning para priorizar baseado em feedback real
- Apresentações de resultados pós-lançamento
- Escalação de problemas críticos identificados via feedback
- Documentação de impacto de mudanças de design

# Onboarding Copy Library

## Context

Biblioteca de copy para fluxos de onboarding — a primeira experiência do usuário
com o produto. O onboarding tem duas missões: (1) coletar dados necessários para
personalizar a experiência e (2) ensinar o usuário a extrair valor do produto o
mais rápido possível (time-to-value).

Copy de onboarding deve ser encorajador, progressivo e respeitar o tempo do usuário.

**Aplicação:** Telas de cadastro, tutoriais, tooltips de primeira vez, welcome screens
**Tom:** User Advocate + Creative Explorer — acolhedor, orientador, progressivo

## Phrases

### Welcome screen
- "Bem-vindo ao [Produto]. Vamos configurar sua conta em poucos passos."
- "Bom ter você aqui. Em 2 minutos sua conta estará pronta."
- "Vamos começar. São [N] passos rápidos para personalizar sua experiência."
- "[Produto] funciona melhor quando conhece você. Vamos personalizar?"

### Progresso do onboarding
- "Passo [N] de [M]" (sempre mostrar progresso)
- "Quase lá — falta só mais [N] passo(s)."
- "Último passo!"
- "Você pode pular e completar depois nas Configurações."

### Coleta de dados — Justificando perguntas
- **Nome:** "Como devemos te chamar?" (mais caloroso que "Nome completo")
- **Email:** "Seu email será usado para login e comunicações importantes."
- **Telefone:** "Opcional. Usamos apenas para segurança da sua conta."
- **Localização:** "Para mostrar conteúdo e ofertas relevantes da sua região."
- **Cargo/Função:** "Para personalizar a experiência ao seu perfil de trabalho."
- **Tamanho do time:** "Para recomendar o plano ideal para você."
- **Objetivo:** "O que você espera alcançar com [Produto]? Isso nos ajuda a personalizar."

### Escolha de preferências
- "Selecione os temas que mais te interessam." (não "Escolha suas categorias")
- "Qual dessas opções melhor descreve seu uso?" (não "Selecione seu caso de uso")
- "Personalize como quiser — você pode mudar depois."
- "Recomendamos essas opções para começar. Ajuste quando quiser."

### Tooltips de primeira vez
- "Novo! [Feature] permite que você [benefício]. Experimente."
- "Dica: [ação] para [resultado]. Você pode desativar essas dicas nas Configurações."
- "Clique aqui para [ação]. É o primeiro passo para [objetivo]."
- "Essa área mostra [conteúdo]. Será preenchida conforme você usar o [Produto]."

### Conclusão do onboarding
- "Tudo pronto! Sua conta está configurada."
- "Pronto para começar. O que você quer fazer primeiro?"
- "Configuração concluída. Aqui estão 3 coisas para explorar:"
- "Bem-vindo ao [Produto]. Se precisar de ajuda, estamos aqui."

### Reengagement (usuário que não completou)
- "Você parou na etapa [N]. Retomar de onde parou?"
- "Falta pouco para completar sua configuração. Continuar?"
- "Sua conta está quase pronta. Complete a configuração para desbloquear [benefício]."

### Checklist de primeiros passos
- "Seu progresso: [N] de [M] passos concluídos"
- "Próximo passo sugerido: [ação]. [Por que importa]."
- "Parabéns! Você completou todos os passos iniciais."
- Checklist items:
  - "Complete seu perfil"
  - "Explore o [área principal]"
  - "Crie seu primeiro [item]"
  - "Convide um colega"
  - "Personalize suas notificações"

## Variations

### Tom por produto
- **B2C:** Casual, empolgado — "Bem-vindo! Vamos explorar juntos."
- **B2B:** Profissional, eficiente — "Configure sua conta em poucos minutos."
- **Fintech:** Seguro, transparente — "Seus dados estão protegidos. Vamos começar."
- **Saúde:** Acolhedor, cuidadoso — "Estamos aqui para ajudar. Primeiro, conheça-nos."

### Formato por plataforma
- **Mobile:** Telas swipeable com ilustração + 1 título + 1 frase + CTA
- **Desktop:** Wizard multi-step com progress bar + fields + contextual help
- **Email:** Série de 3-5 emails com uma ação clara por email

## When to Use

- Design de fluxos de cadastro e primeira experiência
- Revisão de onboarding existente para reduzir drop-off
- Testes de usabilidade de primeira experiência
- Handoff com specs de copy para todos os estados do onboarding

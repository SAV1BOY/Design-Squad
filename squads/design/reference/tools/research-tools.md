# Research Tools



## Metadata

- **Categoria:** UX Research, User Testing, Qualitative Analysis
- **Relevancia para o Squad:** Alta — ferramentas para pesquisa e teste com usuarios
- **Ultima revisao:** 2026-03-06



## Summary

Research tools suportam todo o ciclo de pesquisa de usuario: recrutamento de participantes, conducao de sessoes (moderadas e nao-moderadas), analise e sintese de dados, e comunicacao de findings. Este documento mapeia ferramentas por etapa e contexto, ajudando o squad a escolher a ferramenta certa para cada tipo de pesquisa.





## Key Concepts


### 1. Recruitment Tools

User Interviews: plataforma de recrutamento com painel de participantes qualificados. Respondent: recrutamento para pesquisa paga. Prolific: panel de pesquisa academica/profissional. Para recrutamento interno: formulario de opt-in no produto, customer success referrals, social media outreach.


### 2. Moderated Testing Tools

Lookback: sessoes moderadas remotas com video, audio, screen share e notas timestamped. UserTesting: painel de participantes + plataforma de teste moderado e nao-moderado. Zoom/Google Meet: para sessoes moderadas simples sem features especializadas.


### 3. Unmoderated Testing Tools

Maze: prototipos do Figma transformados em testes nao-moderados com metricas automaticas (success rate, misclick rate, time on task). UsabilityHub (Lyssna): testes rapidos — first click, five second test, preference test, design survey. Optimal Workshop: card sorting, tree testing, first click.


### 4. Analysis and Synthesis Tools

Dovetail: plataforma de research repository — transcrição, tagging, highlight, insight synthesis, searchable database de findings. EnjoyHQ: alternativa a Dovetail com foco em insights. Miro/FigJam: affinity diagramming manual. Notion: documentacao e organizacao de findings.


### 5. Research Repository

Repository centralizado de todos os findings de pesquisa: entrevistas transcritas, insights taggeados, recomendacoes e decisoes tomadas. O repository evita que pesquisa seja feita repetidamente e permite que qualquer membro do time busque evidencia existente. Dovetail e a ferramenta mais madura para isso.



## Application to Design Squad

- **Maze para testes nao-moderados:** Integrar Maze com prototipos do Figma para testes quantitativos rapidos. Usar para validar fluxos antes de implementacao.
- **Dovetail como research repository:** Centralizar todos os findings de pesquisa em Dovetail. Taguear por tema, projeto e data. Antes de nova pesquisa, buscar no repository se ja existe evidencia.
- **Moderated testing mensal:** Manter cadencia mensal de testes moderados (Lookback ou Zoom). Recrutar via User Interviews ou banco proprio de participantes.
- **Optimal Workshop para IA:** Usar card sorting (Optimal Workshop) para validar information architecture antes de redesigns de navegacao.
- **Quick tests via Lyssna:** Para decisoes rapidas (preferencia entre opcoes, first impression), usar Lyssna para testes de 24h com resultados quantitativos.



## Key Takeaways

1. **Cada tipo de pesquisa tem ferramenta ideal.** Moderado, nao-moderado, quantitativo e qualitativo requerem ferramentas diferentes.

2. **Research repository previne desperdicio.** Sem repository, o mesmo insight e "descoberto" repetidamente por times diferentes.

3. **Testes nao-moderados escalam.** Maze e Lyssna permitem testar com dezenas de participantes sem agendar sessoes.

4. **Moderated + unmoderated sao complementares.** Quantitativo (nao-moderado) identifica problemas; qualitativo (moderado) explica por que.

5. **Recrutamento e o maior gargalo.** Investir em banco de participantes e pipeline de recrutamento e tao importante quanto escolher ferramenta de teste.

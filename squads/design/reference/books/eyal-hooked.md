# Hooked — Nir Eyal



## Metadata

- **Autor:** Nir Eyal
- **Publicacao:** 2014
- **Categoria:** Behavioral Design, Product Strategy, Habit Formation
- **Relevancia para o Squad:** Media-Alta — framework para criar produtos formadores de hábito
- **Ultima revisao:** 2026-03-06



## Summary

Hooked apresenta o Hook Model — um framework de quatro fases para criar produtos que formam hábitos de uso sem depender de marketing ou publicidade constante. Eyal argumenta que os produtos mais bem-sucedidos (Instagram, Slack, Google) não competem por atenção a cada uso — eles se incorporam na rotina do usuário através de loops comportamentais repetitivos.

O modelo é: Trigger (externo ou interno) > Action (comportamento mínimo) > Variable Reward (recompensa imprevisível) > Investment (usuário coloca algo de volta no produto). O ciclo se repete, e com cada iteração o produto se torna mais valioso e difícil de abandonar.

Eyal também aborda a ética de manipulação comportamental, propondo o "Manipulation Matrix" para avaliar se o uso do Hook Model é legítimo. O livro se tornou referência tanto para designers que querem criar engagement quanto para os que querem entender (e resistir a) padrões manipulativos.



## Key Concepts


### 1. Hook Model (Trigger > Action > Variable Reward > Investment)

O ciclo completo: um trigger (notificação, emoção interna) leva a uma action (abrir o app, scrollar). A action resulta em variable reward (conteúdo novo e imprevisível). O usuário então investe (cria conteúdo, adiciona dados, personaliza), o que aumenta o valor do produto e torna o próximo ciclo mais provável.


### 2. Internal vs. External Triggers

External triggers são prompts do ambiente (notificações, emails, CTAs). Internal triggers são emoções ou situações que o usuário associa ao produto (tédio > Instagram, solidão > WhatsApp). O objetivo é migrar de triggers externos para internos — quando o produto é a resposta automática a uma emoção, o hábito está formado.


### 3. Variable Rewards (Tribe, Hunt, Self)

Recompensas previsíveis perdem efeito rapidamente (hedonic adaptation). Recompensas variáveis mantêm engajamento. Três tipos: Tribe (social — likes, comentários), Hunt (recursos — deals, conteúdo novo), Self (pessoal — sensação de completude, maestria). Os produtos mais engajadores combinam os três.


### 4. Investment Phase

A fase mais negligenciada: o usuário investe tempo, dados, reputação, conexões ou conteúdo no produto. Cada investimento aumenta o switching cost e melhora o produto para o próximo uso (dados melhoram recomendações, conexões melhoram o feed). O investimento fecha o loop e prepara o próximo trigger.


### 5. Manipulation Matrix (Ethics Framework)

Duas perguntas: "Eu usaria este produto?" e "Isto melhora materialmente a vida do usuário?" Cruzando as respostas: Facilitator (sim/sim — legítimo), Peddler (não/sim — questionável), Entertainer (sim/não — aceitável), Dealer (não/não — antiético). Framework para reflexão ética sobre behavioral design.



## Application to Design Squad

- **Hook audit de features existentes:** Mapear o Hook Model para os fluxos principais do produto. Identificar onde o ciclo está incompleto (trigger sem action clara, action sem reward, reward sem investment).
- **Internal trigger research:** Pesquisar quais emoções ou situações levam usuários ao produto. Esses internal triggers devem ser reforçados, não apenas os external triggers (notificações).
- **Variable reward audit:** Avaliar se as recompensas do produto são variáveis (mantêm curiosidade) ou previsíveis (entediam). Onde possível, adicionar variabilidade controlada.
- **Investment points:** Identificar e fortalecer os pontos de investimento — cada configuração, dado salvo, conteúdo criado, conexão feita aumenta o valor do produto para aquele usuário.
- **Ethics check:** Aplicar a Manipulation Matrix a cada feature comportamental. Documentar a avaliação ética no brief do projeto.



## Key Takeaways

1. **Hábitos reduzem dependência de marketing.** Produtos que formam hábitos crescem organicamente porque os usuários voltam por motivação interna, não por incentivo externo.

2. **Internal triggers são o objetivo final.** Migrar de notificações para associações emocionais é o que diferencia apps "usados" de apps "viciantes."
3. **Variabilidade mantém engagement.** Recompensas previsíveis perdem efeito. Adicionar variabilidade controlada mantém o usuário curioso.

4. **Investimento do usuário é o moat.** Quanto mais o usuário investe no produto, maior o switching cost e mais personalizada a experiência.

5. **Ética é responsabilidade do designer.** O Hook Model é ferramenta poderosa — e poder exige responsabilidade. Use a Manipulation Matrix.

## Instructions (Como Usar)

1. Defina a persona e o cenario especifico antes de mapear a jornada.
2. Mapeie a jornada end-to-end, incluindo momentos fora do produto.
3. Para cada fase, capture acoes, pensamentos, emocoes e touchpoints.
4. Identifique pain points e oportunidades em cada fase.
5. Use como base para priorizar melhorias e alinhar o time.

> **Dica:** Journey maps sao mais eficientes quando criados colaborativamente com o time (PM, eng, CS, design).

## Example (Parcialmente Preenchido)

**Persona:** Renata, Gerente de Marketing
**Jornada:** Primeiro uso do dashboard de analytics
**Fase 3 — Primeiro acesso:** Renata faz login e ve um dashboard vazio. Pensamento: _"E agora? O que eu faco?"_ Emocao: Frustrada (2/5). Pain point: Nenhuma orientacao sobre como configurar o dashboard. Oportunidade: Onboarding guiado com templates pre-prontos.

## Notes

- Journey maps devem ser atualizados quando o produto muda significativamente.
- Combine dados qualitativos (entrevistas) com quantitativos (analytics) para maior precisao.
- Crie versoes visuais (Figma/Miro) alem deste documento para facilitar compartilhamento.
- Considere mapear a jornada do estado atual (as-is) e do estado desejado (to-be).
- Convide stakeholders de diferentes areas para validar as fases e touchpoints.

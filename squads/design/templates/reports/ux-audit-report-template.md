## Instructions (Como Usar)

1. Defina o escopo e os criterios de avaliacao antes de iniciar.
2. Avalie cada fluxo/pagina de forma sistematica usando os criterios escolhidos.
3. Classifique cada finding por severidade para facilitar priorizacao.
4. Inclua screenshots e recomendacoes acionaveis para cada problema.
5. Apresente ao time e defina proximos passos colaborativamente.

> **Dica:** Use as heuristicas de Nielsen ou os principios de usabilidade como framework. Seja consistente na avaliacao.

## Notes

- UX audits sao avaliacoes de especialistas — complementar com testes de usabilidade para validar.
- Inclua evidencias visuais para facilitar a comunicacao com eng e stakeholders.
- Recomendacoes devem ser acionaveis e realistas — evite sugestoes vagas.
- Audite periodicamente (a cada 6-12 meses) para acompanhar evolucao.
- Envolva eng na priorizacao — nem tudo que e problema de UX e facil de corrigir.

## Instructions (Como Usar)

1. Compile dados ao longo do quarter — nao deixe para o final.
2. Inclua metricas quantitativas e narrativas qualitativas.
3. Destaque impacto de design em resultados de negocio.
4. Seja transparente sobre desafios e aprendizados.
5. Use como base para planejamento do proximo quarter.

> **Dica:** Stakeholders querem ver impacto, nao apenas atividade. Conecte entregas de design a resultados de negocio.

## Example (Parcialmente Preenchido)

**Q1 2026 Highlight:** Redesign do checkout resultou em aumento de 18% na conversao e reducao de 25% em tickets de suporte relacionados a pagamento.
**Pesquisa:** 3 rodadas de teste de usabilidade com 15 participantes total. Insight-chave: Usuarios B2B precisam de opcao de faturamento — feature adicionada ao roadmap de Q2.
**Desafio:** Delay de 3 semanas no redesign de onboarding por dependencia de API — aprendizado: alinhar com eng mais cedo no discovery.

## Notes

- Conecte sempre entregas de design a metricas de negocio quando possivel.
- Seja transparente sobre o que nao funcionou — mostra maturidade do time.
- Use visuais (graficos, screenshots, highlight reels) para tornar o report mais engajante.
- Revise as metas do quarter anterior antes de definir as novas.
- Distribua o report em formato acessivel — deck para apresentacao, doc para referencia detalhada.

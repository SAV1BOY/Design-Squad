## Instructions (Como Usar)

1. Defina os breakpoints antes de comecar o layout responsivo.
2. Documente como cada secao/componente se comporta em cada breakpoint.
3. Use este template como referencia para eng durante a implementacao.
4. Teste em dispositivos reais alem de simuladores.
5. Considere touch targets (44x44px min) para breakpoints mobile.

> **Dica:** Foque nas mudancas entre breakpoints, nao em redesenhar para cada tamanho. O layout deve ser fluido.

## Example (Parcialmente Preenchido)

**Pagina:** Product listing page
**Mobile:** Cards em lista vertical (1 coluna), filtros em bottom sheet, navegacao em bottom bar
**Tablet:** Cards em grid 2 colunas, filtros em sidebar colapsavel, navegacao top bar
**Desktop:** Cards em grid 3-4 colunas, filtros em sidebar fixa, navegacao top bar com mega menu

## Notes

- Priorize a experiencia mobile se analytics mostram maioria de acesso mobile.
- Evite esconder conteudo critico em breakpoints menores — adapte, nao esconda.
- Use unidades relativas (rem, %) em vez de pixels fixos sempre que possivel.
- Teste com conteudo real (nao lorem ipsum) para evitar surpresas com textos longos.
- Documente o comportamento de truncamento de texto para cada breakpoint.

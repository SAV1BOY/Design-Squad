## Instructions (Como Usar)

1. Catalogue cada empty state do produto neste documento.
2. Para cada estado, defina a mensagem, visual e acao disponivel.
3. Garanta que o tom de voz seja consistente entre todos os estados.
4. Use empty states como oportunidade de guiar o usuario, nao apenas informar.
5. Revise sempre que novos fluxos ou features forem adicionados.

> **Dica:** Empty states sao frequentemente a primeira experiencia do usuario com uma feature. Faca com que sejam acolhedoras e uteis.

## Example (Parcialmente Preenchido)

**Estado: Lista de projetos — First-use**
- Titulo: "Crie seu primeiro projeto"
- Descricao: "Projetos ajudam voce a organizar tarefas e colaborar com seu time. Comece criando um agora!"
- CTA: "Criar projeto" (Primary button)
- CTA secundario: "Ver tutorial" (Link)
- Ilustracao: Pessoa organizando post-its (style: flat, line art)

## Notes

- Empty states sao frequentemente negligenciados mas impactam muito a primeira impressao.
- Sempre ofereca uma acao — empty states sem CTA deixam o usuario perdido.
- Teste as mensagens com usuarios para garantir clareza.
- Mantenha ilustracoes consistentes em estilo entre todos os empty states.
- Considere animacoes sutis (Lottie) para empty states de first-use para criar engagement.

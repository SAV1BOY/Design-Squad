## Instructions (Como Usar)

1. Crie o style tile apos ter um moodboard aprovado ou direcao visual definida.
2. Preencha cada secao com valores concretos — este documento traduz direcao visual em especificacoes.
3. Apresente para stakeholders e engenharia como ponte entre moodboard e design system.
4. Use como referencia durante a criacao de telas hi-fi para manter consistencia.
5. Atualize quando decisoes visuais mudarem durante o projeto.

> **Dica:** Style tiles nao sao um design system completo. Sao um snapshot das decisoes visuais fundamentais que guiam o restante do trabalho.

## Example (Parcialmente Preenchido)

**Projeto:** Plataforma SaaS de gestao de projetos "TaskFlow"
**Primary:** #2563EB (azul), **Secondary:** #7C3AED (roxo), **Accent:** #F59E0B (amber)
**Tipografia:** Headings em Inter (bold), Body em Inter (regular), Code em JetBrains Mono.
**Botao Primary:** bg #2563EB, text white, border-radius 8px, hover darken 10%.
**Grid:** 4 col mobile (16px gutter), 8 col tablet (24px gutter), 12 col desktop (32px gutter, max 1280px).
**Icones:** Heroicons outline, 1.5px stroke, 24px grid, cor segue neutral-700.

## Notes

- Style tiles sao um passo intermediario entre moodboard e design system — nao substitua nenhum dos dois.
- Valide a paleta de cores com testes de contraste (WCAG AA minimo) antes de aprovar.
- Apresente variantes quando houver indecisao — ex.: duas opcoes de border-radius.
- Documente decisoes rejeitadas e o racional — evita re-discussao.
- Atualize este documento se tokens forem renomeados durante a implementacao.

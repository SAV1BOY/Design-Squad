## Instructions (Como Usar)

1. Use este template apos concluir a coleta de dados de qualquer pesquisa.
2. Preencha os insights com evidencias — nao inclua insights sem dados de suporte.
3. Para cada insight, derive pelo menos uma oportunidade acionavel.
4. Priorize usando a matriz de impacto x esforco na secao 5.
5. Compartilhe com stakeholders para alinhar proximos passos.

> **Dica:** Insights sao declaracoes sobre o que aprendemos. Oportunidades sao direcoes para acao. Mantenha a distincao clara.

## Example (Parcialmente Preenchido)

**Insight 1 — "Filtros invisiveis":** Usuarios novos nao descobrem os filtros avancados de busca porque o botao esta posicionado abaixo do fold. 6 de 8 participantes nao interagiram com filtros sem orientacao.
**Quote:** _"Eu nem sabia que dava pra filtrar por data. Achei que so tinha essa busca basica."_ — P3
**HMW:** How might we tornar os filtros avancados mais descubriveis sem poluir a interface?

## Notes

- Diferencie insight (fato descoberto) de opiniao (interpretacao sem evidencia).
- Use a nomenclatura HMW (How Might We) para formular oportunidades de forma aberta.
- Numere insights e oportunidades para facilitar referencia cruzada em reunioes.
- Atualize este documento conforme novos dados surgem — trate-o como artefato vivo.
- Compartilhe em formato apresentavel (deck ou workshop) alem do documento escrito.

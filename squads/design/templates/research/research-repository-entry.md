## Instructions (Como Usar)

1. Preencha este template para cada pesquisa concluida no time.
2. Mantenha o repositorio centralizado e acessivel para todo o time.
3. Use tags consistentes para facilitar buscas futuras.
4. Vincule insights a outras entradas do repositorio quando houver relacao.
5. Revise entradas antigas periodicamente para atualizar a validade dos insights.

> **Dica:** Um repositorio bem mantido evita pesquisas duplicadas e acelera o onboarding de novos membros do time.

## Example (Parcialmente Preenchido)

**ID:** RES-2026-015
**Titulo:** Entrevistas sobre habitos de pagamento — Segmento PME
**Metodo:** 12 entrevistas semi-estruturadas, 45min cada
**Insight 1:** Donos de PME preferem pagar boletos via app bancario em vez de usar plataformas de pagamento dedicadas — 9 de 12 relataram esse comportamento.
**Status de recomendacao:** Integracao com PIX implementada no Q1 2026 com base neste insight.

## Notes

- Cada entrada deve ter um ID unico para referencia cruzada.
- Use tags padronizadas para facilitar busca (ex.: #onboarding, #pagamento, #mobile).
- Atualize o campo "Status de implementacao" das recomendacoes regularmente.
- Insights com confianca "Baixa" devem ser marcados para validacao futura.
- Incentive todo o time a consultar o repositorio antes de iniciar nova pesquisa.
- Considere fazer "research repository reviews" trimestrais para manter a qualidade.

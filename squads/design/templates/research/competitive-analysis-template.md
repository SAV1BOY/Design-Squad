## Instructions (Como Usar)

1. Identifique 3-6 concorrentes relevantes (diretos e indiretos).
2. Defina os criterios de avaliacao baseados nos objetivos da analise.
3. Analise cada concorrente de forma consistente usando os mesmos criterios.
4. Documente screenshots e evidencias para cada avaliacao.
5. Atualize periodicamente — o cenario competitivo muda constantemente.

> **Dica:** Inclua pelo menos 1 concorrente aspiracional (benchmark fora do seu mercado direto) para expandir a visao.

## Notes

- Atualize esta analise a cada trimestre ou quando concorrentes lancarem updates significativos.
- Nao se limite a copiar features de concorrentes — foque em entender o "por que" por tras das decisoes.
- Combine esta analise com pesquisa de usuarios para validar se os gaps sao realmente relevantes.
- Considere criar alertas (Google Alerts, G2 reviews) para monitorar concorrentes continuamente.
- Evite vies de confirmacao — analise pontos fortes dos concorrentes com a mesma atencao que pontos fracos.

# Conference Speaking Strategy

## Objective

Estrategia para submeter, preparar e apresentar talks em conferencias de design e tecnologia como forma de construir autoridade profissional.

## Target Conferences

```
Tier 1 (Flagship):
- Config (Figma) — design tools e workflow
- An Event Apart — web design e development
- SmashingConf — front-end e UX
- Clarity — design systems

Tier 2 (Regional/Specialized):
- UX Conf BR — UX no Brasil
- Pixel Show — design digital BR
- Front in — front-end BR
- DS Day — design systems

Tier 3 (Meetups e Community):
- Meetups locais de UX/Design
- Company tech talks (convites)
- Webinars e podcasts
```

## Talk Development Process

### 1. Topic Selection
```
Criterios:
- Baseado em experiencia real (nao teoria)
- Relevante para a audiencia da conferencia
- Original ou com angulo novo
- Demonstravel com exemplos concretos
- Alinhado com pilares de autoridade
```

### 2. Proposal Writing
```
Template de submissao:
- Title: curto, especifico, intrigante (max 10 palavras)
- Abstract: 200-300 palavras, problema + o que audiencia aprenderá
- Outline: 3-5 pontos principais
- Bio: relevante para o topico da talk
- Previous talks: links para gravacoes/slides
```

### 3. Talk Preparation
```
Timeline (8 semanas antes):
- Semana 1-2: Outline e pesquisa
- Semana 3-4: Slides e narrativa
- Semana 5-6: Rehearsal (3x minimo)
- Semana 7: Feedback de colegas
- Semana 8: Final polish e backup plans
```

### 4. Delivery Best Practices
```
- Storytelling > bullet points
- Demos ao vivo com safety net (video backup)
- 1 takeaway claro por 10 minutos de talk
- Deixe tempo para Q&A
- Compartilhe slides e resources apos a talk
```

## Notes

- Submeta para 5-10 conferencias por talk (taxa de aceite ~20%)
- Recicle talks adaptando para audiencias diferentes
- Grave todas as talks para portfolio
- Networking no evento e tao valioso quanto a talk em si

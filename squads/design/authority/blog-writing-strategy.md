# Blog Writing Strategy

## Objective

Estrategia para producao de conteudo escrito que demonstre expertise e gere valor para a comunidade de design.

## Content Pillars

```
Pilar                    | Frequencia | Formato
-------------------------|-----------|-------------------
Design Systems           | 2x/mes    | Tutorial, opinion
Accessibility            | 1x/mes    | How-to, case study
UX Metrics               | 1x/mes    | Analysis, framework
Process & Operations     | 1x/mes    | Reflection, guide
```

## Content Types

### 1. Tutorial / How-To (40%)
```
Formato: passo-a-passo com codigo/screenshots
Exemplo: "Como estruturar design tokens em 3 camadas"
Tamanho: 1500-2500 palavras
SEO: alto — resolve problema especifico
```

### 2. Case Study (20%)
```
Formato: narrativa com processo e resultados
Exemplo: "Como reduzimos design debt em 60% em 6 meses"
Tamanho: 2000-3000 palavras
SEO: medio — atrai audiencia qualificada
```

### 3. Opinion / Framework (25%)
```
Formato: tese + argumentos + exemplos
Exemplo: "Por que design quality scores importam mais que velocity"
Tamanho: 1200-2000 palavras
SEO: medio — gera discussao e shares
```

### 4. Curadoria / Resource (15%)
```
Formato: lista comentada de recursos
Exemplo: "10 design systems publicos que todo designer deveria estudar"
Tamanho: 1000-1500 palavras
SEO: alto — atrai via busca especifica
```

## Publishing Workflow

```
1. Ideia capturada (backlog de ideias)
2. Outline (30 min)
3. First draft (2-4 horas)
4. Review (pedir feedback de 1-2 colegas)
5. Edit e polish (1-2 horas)
6. Publish + distribute
7. Engage com comentarios (1 semana)
```

## Distribution

```
Canal            | Acao apos publicar
-----------------|------------------------------------------
LinkedIn         | Post com resumo e link (2-3 paragrafos)
Twitter/X        | Thread com highlights
Dev.to / Medium  | Cross-post (se nao exclusivo)
Newsletter       | Incluir no digest mensal
Slack communities| Compartilhar em canais relevantes
```

## Notes

- Consistencia > perfection — publique regularmente, melhore com o tempo
- Escreva sobre o que voce pratica, nao sobre o que voce leu
- Inclua dados e exemplos reais sempre que possivel
- Responda a todo comentario na primeira semana

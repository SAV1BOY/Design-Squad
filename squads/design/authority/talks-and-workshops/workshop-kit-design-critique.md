# Workshop Kit: Design Critique

## Objective

Kit completo para facilitar um workshop de design critique com o time. Objetivo: melhorar a qualidade do feedback em design reviews e criar cultura de critica construtiva.

## Workshop Overview

```
Duracao: 2 horas
Participantes: 6-12 (designers, idealmente com PMs e devs)
Materiais: FigJam/Miro board, projeto real para critica
Pre-work: participantes revisam o projeto 15 min antes
```

## Agenda

### 1. Opening (15 min)
```
- Boas-vindas e objetivo do workshop
- Ground rules:
  1. Critique o trabalho, nao a pessoa
  2. Seja especifico (nao "eu nao gosto", sim "o contraste aqui dificulta leitura")
  3. Equilibre feedback positivo e construtivo
  4. Pergunte antes de sugerir (entenda o contexto)
  5. Ofereça alternativas, nao apenas problemas
```

### 2. Framework Introduction (15 min)
```
Framework: I Like, I Wish, What If

I Like:   "Gosto de como o spacing cria hierarquia clara entre secoes"
I Wish:   "Gostaria que o CTA primario tivesse mais destaque visual"
What If:  "E se usassemos progressive disclosure para os filtros avancados?"

Regras:
- Sempre comece com I Like (crie ambiente seguro)
- I Wish deve ser especifico e acionavel
- What If e exploratorio — nao precisa ser a solucao
```

### 3. Guided Critique (30 min)
```
Facilitador guia critica de 1 projeto real:
- Apresentador: 5 min de contexto (problema, constraints, decisoes)
- Rodada 1 - I Like: cada participante oferece 1 ponto positivo
- Rodada 2 - I Wish: cada participante oferece 1 area de melhoria
- Rodada 3 - What If: brainstorm aberto de alternativas
- Facilitador documenta feedback em categorias
```

### 4. Pair Critique (30 min)
```
Participantes em pares:
- Cada par recebe um projeto diferente (ou troca projetos entre si)
- 10 min: critique individual usando I Like/I Wish/What If
- 5 min: compartilhar feedback com o par
- Trocar e repetir
```

### 5. Debrief (20 min)
```
Perguntas para grupo:
- O que aprendemos sobre dar feedback?
- O que foi desconfortavel? Como podemos melhorar?
- Como aplicamos isso nas design reviews do dia-a-dia?
- Que regras adicionais o time quer adotar?
```

### 6. Close (10 min)
```
- Resumo de action items
- Proximos passos: aplicar framework na proxima design review
- Feedback survey (5 perguntas, 2 min)
```

## Facilitator Notes

- Se o grupo e silencioso, comece voce com um exemplo de cada categoria
- Se alguem e muito critico, redirecione: "pode reformular como I Wish?"
- Mantenha timebox rigoroso — critique pode se estender indefinidamente
- Documente tudo para enviar apos o workshop

## Notes

- Adapte o framework ao nivel do time (juniores precisam de mais guiding)
- Repita o workshop trimestralmente para reforcar a pratica
- Considere rodar com projetos anonimizados para reduzir defensividade

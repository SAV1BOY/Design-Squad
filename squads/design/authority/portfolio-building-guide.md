# Portfolio Building Guide

## Objective

Guia para construir um portfolio de design que demonstre profundidade de processo, impacto mensuravel e pensamento estrategico.

## Portfolio Structure

### Essential Pages
```
1. Homepage: hero + 3-4 featured projects + bio curto
2. About: historia profissional, valores, skills
3. Case Studies: 3-5 projetos detalhados
4. Contact: formas de contato e availability
```

### Case Study Structure (per project)
```
1. Hero: titulo + role + timeline + imagem impactante
2. Context: problema + constraints + equipe
3. Process: research → ideation → design → iteration
4. Solution: resultado final com detalhes visuais
5. Results: metricas + impacto + learnings
```

## Content Strategy

### Project Selection
```
Criterio                   | Peso
---------------------------|------
Demonstra processo         | Alto
Tem resultados mensuraveis | Alto
Mostra colaboracao         | Medio
Visual impactante          | Medio
Relevante para target role | Alto
```

### Visual Presentation
```
- Hero images em alta qualidade
- Mockups em contexto (dispositivos reais)
- Process artifacts (sketches, wireframes, flows)
- Before/after comparisons
- Data visualizations para resultados
- Responsive: seu portfolio DEVE funcionar em mobile
```

## Technical Considerations

```
Plataforma       | Pros                     | Contras
-----------------|--------------------------|------------------
Portfolio site   | Controle total           | Tempo de manutencao
Notion           | Rapido, facil update     | Menos customizavel
Read.cv          | Design-focused, clean    | Limitado
Webflow          | Visual + custom          | Learning curve
```

## Common Mistakes

```
Erro                              | Correcao
----------------------------------|----------------------------------
Mostrar apenas telas finais       | Inclua processo e iteracoes
Sem metricas ou resultados        | Quantifique impacto sempre
Portfolio nao responsivo           | Mobile-first design
Projetos demais (10+)             | Foque em 3-5 melhores
Copy generico                     | Storytelling especifico
Sem CTA de contato                | CTA claro em toda pagina
```

## Maintenance

```
Frequencia     | Acao
---------------|------------------------------------------
Mensal         | Revisar analytics do portfolio
Trimestral     | Atualizar projetos com novos dados
Semestral      | Adicionar/remover projetos
Anual          | Redesign se necessario
```

## Notes

- Portfolio e sua melhor ferramenta de carreira — invista nele
- Menos e mais — 3 case studies excelentes > 10 mediocres
- Peca feedback de outros designers antes de publicar
- Teste com recrutadores e PMs para validar clareza

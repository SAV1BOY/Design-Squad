# Workshop Facilitation Strategy

## Objective

Estrategia para facilitar workshops de design que educam, engajam e geram resultados praticos para os participantes.

## Workshop Types

### 1. Design Critique Workshop (2h)
```
Objetivo: melhorar a qualidade de feedback em reviews
Participantes: 6-12 designers
Formato:
- 20min: framework de critica (I like, I wish, What if)
- 30min: critica guiada de um projeto real
- 30min: critica em pares (2 rodadas)
- 20min: debrief e next steps
- 20min: buffer e perguntas
```

### 2. Design Tokens Workshop (3h)
```
Objetivo: entender e implementar design tokens
Participantes: 4-8 designers + developers
Formato:
- 30min: conceito de tokens e beneficios
- 45min: hands-on — criar token structure
- 30min: implementar tokens (CSS custom properties)
- 45min: exercicio — tokenizar um componente real
- 30min: debrief e aplicacao no projeto
```

### 3. Accessibility Audit Workshop (4h)
```
Objetivo: conduzir auditoria de a11y em produto real
Participantes: 6-10 multidisciplinar
Formato:
- 30min: WCAG overview e ferramentas
- 60min: audit hands-on com axe-core e keyboard
- 30min: screen reader testing demo
- 60min: classificar e priorizar findings
- 30min: criar plano de remediacao
- 30min: debrief
```

### 4. Design Sprint Facilitation (5 days)
```
Objetivo: resolver desafio de produto em 5 dias
Participantes: 5-7 multidisciplinar
Formato Google Ventures Design Sprint:
- Day 1: Understand (map, interviews, HMW)
- Day 2: Sketch (lightning demos, crazy 8s)
- Day 3: Decide (vote, storyboard)
- Day 4: Prototype (realistic prototype)
- Day 5: Test (5 user tests)
```

## Facilitation Best Practices

```
Antes:
- Defina objetivo e outcome esperado
- Prepare materiais e templates
- Envie pre-work aos participantes
- Teste ferramentas (Miro, FigJam, Zoom)

Durante:
- Comece com icebreaker e ground rules
- Timeboxe todas as atividades
- Use parking lot para tangentes
- Garanta que todos participem (silent brainstorm)
- Documente decisions em tempo real

Depois:
- Envie summary com action items
- Follow-up em 1 semana
- Colete feedback (survey)
- Itere o formato baseado em feedback
```

## Notes

- Facilitar e diferente de apresentar — seu papel e guiar, nao ensinar
- Workshops presenciais > remotos para engajamento
- Limite a 12 participantes para interacao eficaz
- Sempre tenha um co-facilitator para grupos > 8

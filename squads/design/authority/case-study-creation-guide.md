# Case Study Creation Guide

## Objective

Guia para criar case studies de design impactantes que demonstrem processo, decisoes e resultados mensuráveis. Case studies sao a principal ferramenta de autoridade profissional.

## Structure Template

### 1. Context (10% do conteudo)
```
- Empresa/produto e seu mercado
- Desafio ou oportunidade de negocio
- Seu papel e o do time
- Timeline do projeto
- Constraints relevantes (tech, budget, timeline)
```

### 2. Process (50% do conteudo)
```
- Research: metodos usados e insights-chave
- Ideation: como explorou solucoes
- Design decisions: opcoes consideradas e por que escolheu cada uma
- Iteration: como prototipos evoluiram com feedback
- Collaboration: como trabalhou com eng, PM, stakeholders
```

### 3. Solution (20% do conteudo)
```
- Solucao final com imagens/prototipos
- Principios de design que guiaram a solucao
- Trade-offs aceitos e justificativa
- Detalhes de implementacao relevantes
```

### 4. Results (20% do conteudo)
```
- Metricas quantitativas (conversao, NPS, task completion)
- Feedback qualitativo (citacoes de usuarios/stakeholders)
- Impacto de negocio (receita, retencao, custos)
- Licoes aprendidas (o que faria diferente)
```

## Writing Tips

```
Do                              | Don't
--------------------------------|--------------------------------
Mostre decisoes, nao apenas telas| Apresente apenas resultado final
Inclua metricas reais           | Use metricas vagas
Explique trade-offs             | Finja que tudo foi perfeito
Credite o time                  | Tome credito sozinho
Mostre iteracoes e falhas       | Mostre apenas a versao final
Use storytelling                | Liste features
```

## Visual Guidelines

- Hero image: solucao final em contexto de uso
- Before/after comparisons quando aplicavel
- Process photos: sketches, whiteboards, sticky notes
- Data visualizations para resultados
- Responsive: funcional em mobile

## Distribution Channels

```
Canal               | Formato              | Audiencia
--------------------|---------------------|-------------------
Portfolio pessoal   | Long-form + visuals  | Recrutadores, peers
Medium/Blog         | Artigo 8-12 min read | Comunidade de design
LinkedIn            | Summary + link       | Network profissional
Dribbble/Behance    | Visual-heavy         | Designers
Conference talk     | Presentation         | Industria
```

## Notes

- Um bom case study leva 2-4 semanas para produzir
- Obtenha permissao do cliente/empresa antes de publicar
- Atualize case studies anualmente com dados de longo prazo
- Mantenha 3-5 case studies ativos no portfolio

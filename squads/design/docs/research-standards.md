# Research Standards

## Overview

Padrões de pesquisa de usuário do Design Squad — define métodos, processos,
critérios de qualidade e templates para garantir que toda pesquisa seja rigorosa,
ética e acionável. Pesquisa de qualidade é a base de design evidence-driven.

## Content

### Princípios de Pesquisa

1. **Pesquisa informa, não valida** — Pesquise para aprender, não para confirmar
2. **Método segue pergunta** — Escolha o método baseado no que precisa descobrir
3. **Representatividade importa** — Incluir diversidade de perfis e contextos
4. **Ética é inegociável** — Consentimento informado, anonimização, transparência
5. **Insight sem ação é desperdício** — Todo insight deve levar a uma decisão

### Métodos e Quando Usar

| Método | Quando usar | Sample size | Duração |
|--------|-------------|-------------|---------|
| Entrevista em profundidade | Explorar motivações e contextos | 5-8 | 45-60 min cada |
| Teste de usabilidade | Avaliar eficácia de interface | 5-8 | 30-45 min cada |
| Card sorting | Definir arquitetura de informação | 15-30 | 15-20 min cada |
| Tree testing | Validar navegação | 30-50 | 10-15 min cada |
| Survey | Quantificar opiniões e comportamentos | 100+ | 5-10 min cada |
| A/B Test | Comparar variantes com dados reais | 1000+/variante | 1-4 semanas |
| Diary study | Comportamento ao longo do tempo | 10-15 | 1-4 semanas |
| Análise heurística | Avaliação rápida por experts | 3-5 experts | 2-4 horas |
| Benchmark | Comparar com concorrentes e referências | 5-10 concorrentes | 2-3 dias |

### Processo de Pesquisa

#### 1. Planejamento
- Definir research questions (máximo 3 perguntas por estudo)
- Escolher método(s) adequado(s) às perguntas
- Definir critérios de recrutamento
- Criar plano de pesquisa (template abaixo)
- Review do plano pelo design lead

#### 2. Recrutamento
- Banco de participantes interno + recrutamento externo
- Diversidade obrigatória: idade, gênero, localização, proficiência digital
- Incluir pessoas com deficiência em pelo menos 20% dos estudos
- Compensação justa: R$ [valor]/hora para participantes externos
- Consentimento informado assinado antes de qualquer sessão

#### 3. Coleta
- Facilitador + observador (mínimo 2 pessoas)
- Gravação com consentimento explícito
- Notas estruturadas em tempo real
- Não liderar respostas — perguntas abertas

#### 4. Análise
- Análise temática para dados qualitativos
- Codificação de temas com 2+ pesquisadores (interrater reliability)
- Triangulação com dados quantitativos quando disponível
- Separar observação de interpretação

#### 5. Comunicação
- Report estruturado (template abaixo)
- Readout para stakeholders em até 1 semana
- Insights adicionados ao Research Repository
- Action items definidos e trackeados

### Templates

#### Template de Plano de Pesquisa
```
# Plano de Pesquisa — [Título]

## Research Questions
1. [Pergunta principal]
2. [Pergunta secundária]
3. [Pergunta secundária]

## Método
[Método escolhido] — Justificativa: [por que esse método]

## Participantes
- Perfil: [critérios de inclusão/exclusão]
- Quantidade: [N]
- Recrutamento: [fonte]
- Compensação: [valor]

## Cronograma
- Recrutamento: [datas]
- Sessões: [datas]
- Análise: [datas]
- Report: [data]

## Script/Guia
[Link para script de entrevista ou protocolo de teste]
```

#### Template de Report de Pesquisa
```
# Research Report — [Título]

## TL;DR
[3 frases: o que fizemos, o que descobrimos, o que recomendamos]

## Metodologia
- Método: [qual]
- Participantes: [N] ([perfil])
- Período: [datas]

## Key Insights
### Insight 1: [Título]
- Evidência: [dados que suportam]
- Impacto: [como afeta a experiência]
- Recomendação: [ação sugerida]

## Limitações
[O que este estudo não cobre]

## Próximos Passos
[Ações e responsáveis]
```

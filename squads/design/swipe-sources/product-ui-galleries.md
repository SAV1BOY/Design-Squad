# Product UI Galleries

## Pattern Description

Indice de galerias de screenshots de UIs de produtos reais. Fonte primaria para referencia de padroes de interfaces em producao.

## Examples

### Example 1: Mobbin (mobbin.com)
Maior galeria de mobile e web UI patterns:
- 300K+ screenshots de apps e websites reais
- Filtros: plataforma, categoria, flow type, componente
- Collections curatorias por tema
- Atualizacao continua com novas versoes de apps
- Planos free e pro

### Example 2: Screenlane (screenlane.com)
Galeria focada em mobile UI:
- Screenshots organizados por pattern (onboarding, search, settings)
- Filtros por app e categoria
- Formato visual limpo para comparacao
- Curadoria manual de qualidade

### Example 3: Page Flows (pageflows.com)
Foco em fluxos completos (nao apenas telas individuais):
- Videos de fluxos inteiros (signup, checkout, onboarding)
- Contexto de cada passo do fluxo
- Filtros por tipo de fluxo e industria
- Recordings atuais de produtos conhecidos

## Analysis

Galerias de UI sao uteis para:
- Referencia rapida de como produtos resolvem problemas comuns
- Competitive analysis de interfaces
- Inspiracao contextualizada (nao abstrata)
- Alinhamento de expectativas com stakeholders

Dica: use galerias para benchmarking, nao para copiar — adapte padroes ao seu contexto.

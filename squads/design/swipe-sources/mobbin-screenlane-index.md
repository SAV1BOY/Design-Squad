# Mobbin & Screenlane Index

## Pattern Description

Guia de uso eficaz do Mobbin e Screenlane como ferramentas de referencia para UX patterns em produtos reais.

## Examples

### Example 1: Mobbin — Pattern Research Workflow
Workflow de pesquisa de padroes no Mobbin:
- Busca por flow type: "onboarding", "checkout", "settings"
- Filtro por plataforma (iOS, Android, Web)
- Compare 3-5 implementacoes do mesmo padrao
- Salve em collections por projeto/feature
- Exporte screenshots para moodboard

### Example 2: Screenlane — Mobile-First Reference
Uso do Screenlane para referencia mobile:
- Screenshots de alta qualidade de apps reais
- Filtro por tipo de tela (login, feed, profile)
- Navegacao rapida por app (todas as telas de um app)
- Atualizacao frequente com versoes mais recentes
- Complementa Mobbin com foco mobile exclusivo

### Example 3: Combinacao com Swipe File
Integracao com swipe file interno:
- Use Mobbin/Screenlane para discovery
- Salve as melhores referencias no swipe file interno
- Adicione analise propria (por que funciona, o que copiar)
- Referencie em specs de design e proposals
- Atualize swipe file mensalmente com novas descobertas

## Analysis

Uso eficaz de ferramentas de referencia:
- **Research, nao browsing**: entre com pergunta especifica
- **Comparacao**: compare multiplas solucoes para o mesmo problema
- **Contexto**: entenda o produto e o publico de cada referencia
- **Documentacao**: registre insights, nao apenas screenshots
- **Atualidade**: apps mudam frequentemente — re-verifique referencias

# Accessibility Best Practices Sources

## Pattern Description

Indice de fontes de referencia para melhores praticas de acessibilidade digital. Recursos essenciais para equipes que buscam conformidade WCAG e inclusao.

## Examples

### Example 1: W3C WAI (w3.org/WAI)
Fonte oficial de padroes de acessibilidade:
- WCAG 2.2 Guidelines completas
- WAI-ARIA Authoring Practices (padrao de referencia)
- Tutorials por componente (forms, tables, images)
- Tools list (avaliacoes, extensoes, simuladores)
- Atualizacao continua com novas versoes

### Example 2: A11y Project (a11yproject.com)
Recurso community-driven e acessivel:
- Checklist WCAG simplificada e acionavel
- Posts educativos organizados por topico
- Resources e tools curados
- Linguagem acessivel (menos tecnica que W3C)
- Open source — aceita contribuicoes

### Example 3: Deque University (dequeuniversity.com)
Plataforma educacional de acessibilidade:
- Cursos por role (designer, developer, tester, PM)
- axe-core (ferramenta de teste mais usada)
- ARIA patterns com live examples
- Certificacao IAAP preparatoria
- Blog com analises de padroes

## Analysis

Fontes de a11y essenciais por perfil:
- **Designers**: A11y Project, Stark blog, inclusive-components.design
- **Developers**: WAI-ARIA Practices, MDN a11y docs, axe-core
- **Testers**: Deque University, WAVE, Lighthouse
- **PMs**: WebAIM articles, disability statistics, legal compliance
- **Todos**: WCAG Quick Reference (w3.org/WAI/WCAG22/quickref/)

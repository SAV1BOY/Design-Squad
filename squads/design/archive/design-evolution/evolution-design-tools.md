# Evolution of Design Tools

## Overview

Evolucao das ferramentas de design de interface, de Photoshop a Figma e alem, documentando como cada geracao mudou o processo de design.

## Timeline

### 1990s-2010: Photoshop Era
```
Ferramenta: Adobe Photoshop
- Design de interfaces em ferramenta de foto
- Layers como organizacao primaria
- Export de slices para developers
- PSD como formato de entrega
- Nenhuma feature especifica para UI
- "Redline" specs manuais
```

### 2010-2014: Dedicated UI Tools
```
Ferramentas: Sketch, Adobe XD (conceito)
- Sketch (2010): primeiro tool dedicado a UI design
- Symbols: components reutilizaveis
- Artboards: multiple screens in one file
- Plugins ecosystem (Craft, Zeplin)
- Mudanca de PSD para .sketch como padrao
- Developers usam Zeplin/InVision para specs
```

### 2014-2018: Prototyping Integration
```
Ferramentas: InVision, Principle, Framer
- InVision: prototipos clicaveis de telas estaticas
- Principle: animacoes e transicoes de tela
- Framer: prototipos com codigo
- Marvel, Proto.io como alternativas
- Design e prototipo comecam a convergir
```

### 2016-2020: Figma Revolution
```
Ferramenta: Figma
- Browser-based (sem instalacao)
- Real-time collaboration (Google Docs para design)
- Auto Layout (responsive components)
- Design System features nativas (components, styles)
- Developer handoff integrado (Inspect mode)
- Plugin ecosystem robusto
- Gratuito para individuais
- Mudanca da industria: Sketch → Figma migration
```

### 2020-presente: AI-Powered Design
```
Ferramentas: Figma AI, Galileo, Uizard, v0
- AI para geracao de layouts e componentes
- Design-to-code automation
- Figma Dev Mode para developers
- Variables (tokens nativos no Figma)
- AI suggestions dentro do workflow
- Cursor, v0, Bolt para code-first design
```

## Market Share Shift

```
Ano  | Ferramenta Dominante | Market Share (estimado)
-----|---------------------|------------------------
2014 | Sketch              | 60%+
2018 | Sketch/Figma        | 40%/30%
2020 | Figma               | 55%+
2023 | Figma               | 80%+
2026 | Figma + AI tools    | Figma 70%, AI-native 15%
```

## Lessons

- Collaboration > features (Figma venceu por colaboracao, nao por ferramentas)
- Browser-based elimina barreiras de entrada
- Ferramentas moldam processo — auto-layout mudou como designers pensam
- AI assistira, nao substituira, o processo de design
- Design-to-code gap esta diminuindo progressivamente

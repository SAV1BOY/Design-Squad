# Airbnb Design System Journey

## Overview

A jornada do Airbnb na construcao de um dos design systems mais influentes da industria — do DLS (Design Language System) ao sistema unificado cross-platform.

## Timeline

### 2013-2015: Pre-Design System
```
Contexto:
- Time de design crescendo rapidamente (10 → 40+ designers)
- Inconsistencia visual entre plataformas (Web, iOS, Android)
- Cada designer criando componentes do zero
- Retrabalho estimado em 30% do tempo de design
```

### 2016: DLS (Design Language System) v1
```
Lancamento interno:
- Linguagem visual unificada (cores, tipografia, iconografia)
- Biblioteca Sketch compartilhada
- Componentes basicos padronizados (botoes, inputs, cards)
- Cross-platform: mesmos componentes em Web, iOS, Android
- Resultado: reducao de 50% no tempo de design de telas
```

### 2017-2018: Lottie e Motion
```
Inovacao em motion:
- Lottie: biblioteca open-source para animacoes After Effects → mobile
- Motion como parte integral do design system
- Transicoes padronizadas entre telas
- Loading animations unificadas
- Impacto: Lottie adotado por milhares de empresas
```

### 2019: Componentes React Nativos
```
Unificacao tech:
- React Native como base para mobile
- Componentes compartilhados entre plataformas
- Design tokens como source of truth
- Figma como ferramenta primaria (migracao de Sketch)
- Storybook para documentacao interativa
```

### 2020-presente: Design System Maturo
```
Estado atual:
- 100+ componentes mantidos
- Design tokens em JSON (Style Dictionary)
- Acessibilidade integrada ao processo
- Governance com RFC model
- Metricas de adocao automatizadas
```

## Key Innovations

```
Inovacao               | Impacto
-----------------------|------------------------------------------
Cross-platform DLS     | Pioneiro em DS verdadeiramente unificado
Lottie                 | Padrao da industria para motion
Airbnb Cereal (font)   | Custom font como branding via DS
Token-first approach   | Influenciou adocao de tokens na industria
```

## Lessons Learned

- Comece pelo problema (inconsistencia), nao pela solucao (design system)
- Cross-platform unificado requer investimento continuo significativo
- Open source (Lottie) constroi autoridade e recruta talentos
- Metricas de adocao sao essenciais para justificar investimento
- Design system e produto — precisa de roadmap, backlog e PM
